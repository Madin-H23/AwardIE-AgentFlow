# 大创抽取器设计文档

## 一、概述

大创抽取器（`InnovationExtractor`）用于从Excel文件中抽取大学生创新创业训练项目数据。它是新框架 (`backend/extract/framework.py`) 下的一个抽取器实现。

## 二、设计目标

1. **接口适配**：完全符合 `Extractor` 接口
2. **配置驱动**：所有可配置项通过 `config/settings.json` 管理
3. **灵活解析**：支持多种Excel格式和列名变体
4. **准确识别**：精确识别大创文件和项目数据

### 4.2 关键方法说明

#### 1. `matches_extension(ext: str) -> bool`
```python
def matches_extension(self, ext: str) -> bool:
    """检查文件扩展名是否支持"""
    return ext.lower() in self._extensions
```

#### 2. `matches_keywords(text: str) -> bool`
```python
def matches_keywords(self, text: str) -> bool:
    """大创抽取器不使用关键词匹配（基于文件扩展名）"""
    return False
```

#### 3. `extract(ctx: ExtractContext) -> ExtractResult`
```python
def extract(self, ctx: ExtractContext) -> ExtractResult:
    """主抽取方法"""
    # 1. 读取Excel
    rows = self._read_excel(ctx.file_path)

    # 2. 检查是否为大创文件
    if not self._is_innovation_file(rows, filename):
        return self._other_result("不是大创文件")

    # 3. 查找表头行
    header_idx = self._find_header_row(rows)

    # 4. 筛选目标系别
    data_rows = self._filter_by_department(rows, columns)

    # 5. 抽取项目
    projects = self._extract_projects(data_rows, columns)

    # 6. 验证数据
    validated = self._validate(projects)

    return ExtractResult(
        status=ExtractStatus.SUCCESS,
        data={"projects": validated, "count": len(validated)},
        template_type=TemplateType.INNOVATION,
    )
```

## 六、验证规则

### 6.1 学号验证
- 固定长度：**9位数字**
- 正则：`^\d{9}$`

### 6.2 姓名验证
- 长度：2-5字符
- 不包含数字

### 6.3 级别验证
- 允许值：`["国家级", "省级", "院级"]`
- 支持值映射（从配置读取）

### 6.4 必需字段
- **项目名称**：必须非空
- **年份**
- **项目级别**
- **负责人（姓名和学号）**
- **指导教师（姓名）**

## 七、错误处理

### 7.1 错误类型

| 错误 | 说明 | 返回 |
|------|------|------|
| 文件不存在 | `pathlib.Path.exists()` 返回 False | `FILE_ERROR` |
| 无法读取Excel | openpyxl/xlrd 读取失败 | `NO_TEMPLATE` |
| 不是大创文件 | 文件名和第一行都不含关键词 | `NO_TEMPLATE` |
| 未找到表头 | 没有行包含足够的关键词 | `NO_TEMPLATE` |
| 没有数据 | 筛选后没有目标系别的数据 | `NO_TEMPLATE` |

## 十、结果页与文件生命周期

### 10.1 结果页（按文件分页）

- **分页单位**：每个大创文档（每个 Excel）一页；多文件时通过「上一项/下一项」切换当前文件（`index` 为文件下标）。
- **布局**：左侧为当前文件的源文件预览/下载（较小列）；右侧为当前文件下的项目表格。
- **表格列**：#、项目编号、项目名称、年份、级别、负责人、指导教师、其他成员、验收等级、验证结果（不展示起止时间）。每行有「删除」「编辑」。
- **编辑**：点击编辑进入该文件下某一项目的编辑表单；保存时更新 `achievement_data.projects[project_index]` 并写回 pending。
- **删除**：删除当前文件下某一项目（从 `projects` 中移除该项）；若 `projects` 变为空，则删除该 pending 记录并调用 `safe_delete_with_file` 删除 Excel 文件。
- **全部提交/全部放弃**：仅针对当前页对应的大创文件（即当前这条 pending）；大创时传 `pending_ids: [current_file_item.id]`，后端仅处理这些 ID。

### 10.2 文件与 pending_achievements 引用

- **pending_achievements**：大创为一文件一条记录，`file_path` 指向该 Excel，`achievement_data` 为 `{"projects": [...], "count": N, ...}`。
- **文件删除时机**：大创文档在离开 review 目录（未归档）前必须存在，便于审核与核对。仅当该文件下所有大创条目均被删除（该 pending 被删或 `projects` 清空后删记录）后，才删除该 Excel；`count_by_file_path`、`safe_delete_with_file` 已实现「删记录后若无其他引用再删文件」。
- **归档后**：审核通过入库后，原始文件可删除的逻辑可在归档流程中单独处理；本设计不改变「未归档前不删文件」的语义。

### 10.3 API 约定

- **删除单行项目**：`POST /admin/file-import/api/delete`，请求体 `tab_type=innovation`、`item_id=pending_id`、`project_index=i`；后端从 `projects` 中移除下标 `i`，若 `projects` 为空则删除 pending 并删文件。
- **编辑单行项目**：`POST /admin/file-import/api/submit`，请求体 `achievement_type=innovation`、`item_id=pending_id`、`project_index=i` 及表单字段；后端更新 `achievement_data.projects[i]` 后可选提交审核。
- **全部提交/全部放弃**：大创时请求体传 `pending_ids: [当前文件 pending_id]`，后端仅处理该列表。

## 十四、API参考

### 13.1 InnovationExtractor

```python
class InnovationExtractor(Extractor):
    """大创项目抽取器"""

    name: str = "innovation"
    description: str = "大学生创新创业训练项目抽取器"
    keywords: List[str] = []  # 不使用关键词匹配
    extensions: List[str] = [".xlsx", ".xls"]
    judgment_text: str = "识别Excel格式的大创项目列表文件"

    def __init__(self, config: Dict[str, Any])
    def extract(self, ctx: ExtractContext) -> ExtractResult

    # 私有方法
    def _read_excel(self, file_path: str) -> List[List]
    def _is_innovation_file(self, rows: List, filename: str) -> bool
    def _find_header_row(self, rows: List) -> Optional[int]
    def _filter_by_department(self, rows: List, columns: List) -> List[List]
    def _extract_projects(self, rows: List, columns: List) -> List[Dict]
    def _validate(self, projects: List) -> List[Dict]
```

### 13.2 工厂方法

```python
@classmethod
def from_config_loader(cls, config_loader) -> "InnovationExtractor":
    """从配置加载器创建抽取器实例"""
    config = config_loader.load_config()
    innovation_cfg = config.get("extract", {}).get("innovation", {})
    return cls(innovation_cfg)
```
