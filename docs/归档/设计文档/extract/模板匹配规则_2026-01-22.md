# 模板匹配规则

**文档日期**: 2026-01-22  
**适用范围**: 奖状模板匹配逻辑

---

## 一、整体匹配流程

模板匹配采用**两阶段匹配策略**：

```
1. 类型匹配 (TypeMatcher.match)
   └─ 识别文档类型: award / patent / software / other
   
2. 根据类型选择匹配策略
   ├─ patent/software → 简单匹配 (_match_simple_type)
   └─ award → 复杂匹配 (_match_award)
```

本文档主要说明**奖状模板（award）**的匹配规则。

---

## 二、奖状模板匹配流程

### 阶段1：关键词匹配（优先）

#### 1.1 匹配条件

- **方法**: `template.match_by_keywords(ocr_text)`
- **规则**: 模板的**所有关键词**都必须在OCR文本中出现（AND关系）
- **不检查**: 字符数限制（min_length/max_length）
- **文本清理**: 自动去除标点符号、空格、换行符后进行匹配

#### 1.2 匹配逻辑

```python
for 模板 in 所有奖状模板:
    if 模板的所有关键词都在OCR文本中:
        添加到匹配列表
```

#### 1.3 多模板匹配时的选择规则

**关键规则：如果多个模板同时匹配，选择关键词数量最多的模板**

```python
if 匹配列表长度 > 1:
    按关键词数量排序（降序）
    选择关键词最多的模板
```

**示例**：
- 模板A：关键词 = ["蓝桥杯", "优秀指导教师"] → 2个关键词
- 模板B：关键词 = ["蓝桥杯"] → 1个关键词
- OCR文本包含："蓝桥杯" 和 "优秀指导教师"
- **结果**: 选择模板A（关键词更多）

#### 1.4 匹配成功

如果关键词匹配成功，**直接返回**匹配的模板，不再进行相似度匹配。

---

### 阶段2：相似度匹配（关键词未命中时）

当**没有模板通过关键词匹配**时，进入相似度匹配阶段。

#### 2.1 相似度计算

**方法**: `template.match_score(ocr_text)`

**计算规则**（按顺序检查，任一不满足返回0.0）：

1. **字符数下限检查**
   ```
   if OCR文本长度 < min_length:
       return 0.0
   ```

2. **字符数上限检查**
   ```
   if max_length > 0 and OCR文本长度 > max_length:
       return 0.0
   ```

3. **关键词检查**
   ```
   if 模板有关键词:
       for 关键词 in 模板.keywords:
           if 关键词不在OCR文本中:
               return 0.0
   ```

4. **相似度计算**
   ```
   if 模板有样本文本:
       使用 SequenceMatcher 计算 OCR文本 与 样本文本 的相似度
       return 相似度分数 (0.0-1.0)
   else:
       return 1.0
   ```

#### 2.2 选择最佳模板

```python
for 模板 in 所有奖状模板:
    分数 = 模板.match_score(ocr_text)
    if 分数 > 最佳分数:
        最佳分数 = 分数
        最佳模板 = 模板
```

#### 2.3 阈值检查

**默认阈值**: 0.3（可从配置文件读取）

```python
阈值 = TypeMatcher._rules.get("award", {}).get("similarity_threshold", 0.3)

if 最佳分数 >= 阈值:
    进入竞赛名称验证
else:
    使用默认提示词
```

#### 2.4 竞赛名称验证

如果相似度匹配成功，进行竞赛名称验证：

```python
matched_comp = CompetitionMatcher.match(ocr_text)  # 从OCR文本提取竞赛名称
template_comp = 最佳模板.default_fields.get("competition_name", "")

if matched_comp == template_comp:
    # 竞赛名称匹配，返回模板
    return 最佳模板
elif not matched_comp:
    # 未匹配到竞赛名称，但相似度足够高，仍然返回（可能是新竞赛）
    return 最佳模板
else:
    # 竞赛名称不匹配，使用默认提示词
    return None
```

---

### 阶段3：使用默认提示词

如果**关键词匹配失败**且**相似度匹配失败**（或竞赛名称验证失败），则：

```python
return MatchResult(
    type="award",
    template=None,
    similarity=最佳分数,
    default_prompt=default_prompts.get("award")
)
```

## 三、角色处理

### 3.1 角色确定

**重要**: 匹配到模板后，根据**模板的 `granted_role` 字段**决定是教师还是学生模板。

- 模板的 `default_fields` 中包含 `granted_role` 字段
- 值可以是 `"学生"` 或 `"教师"`
- 如果未设置，默认为 `"学生"`

### 3.2 角色与匹配的关系

- **匹配阶段不进行角色检测**
- **匹配完成后**，使用匹配到的模板的 `granted_role` 字段
- 例如：如果匹配到关键词为 `["蓝桥杯", "优秀指导教师"]` 的模板，该模板的 `granted_role` 为 `"教师"`，则按教师模板进行抽取

---

## 四、匹配优先级总结

完整优先级（从高到低）：

1. ✅ **关键词匹配成功** → 选择关键词数量最多的模板 → **直接返回**
2. ✅ **相似度匹配成功 + 竞赛名称验证通过** → 返回模板
3. ✅ **相似度匹配成功 + 未匹配到竞赛名称** → 返回模板（可能是新竞赛）
4. ❌ **所有匹配失败** → 使用默认提示词

---

## 五、关键方法说明

### 5.1 `template.match_by_keywords(ocr_text)`

- **用途**: 关键词匹配（不检查长度）
- **返回**: `bool` - 是否匹配
- **规则**: 所有关键词都必须命中（AND关系）

### 5.2 `template.match_score(ocr_text)`

- **用途**: 计算相似度分数（检查长度、关键词、相似度）
- **返回**: `float` - 匹配分数 (0.0-1.0)
- **规则**: 按顺序检查字符数、关键词、相似度

### 5.3 `CompetitionMatcher.match(ocr_text)`

- **用途**: 从OCR文本中提取竞赛名称
- **返回**: `str` - 竞赛名称或 `None`

## 六、匹配示例

### 示例1：关键词匹配（多个模板匹配）

**场景**：
- 模板7：关键词 = `["蓝桥杯", "优秀指导教师"]`，`granted_role = "教师"`
- 模板6：关键词 = `["蓝桥杯"]`，`granted_role = "学生"`
- OCR文本：包含 "蓝桥杯" 和 "优秀指导教师"

**匹配过程**：
1. 模板7：关键词全部命中 ✅
2. 模板6：关键词全部命中 ✅
3. 多个模板匹配，按关键词数量排序
4. 模板7有2个关键词，模板6有1个关键词
5. **选择模板7**（关键词更多）
6. 使用模板7的 `granted_role = "教师"` 进行抽取

**结果**: 匹配到教师模板 ✅

### 示例2：关键词匹配（单个模板匹配）

**场景**：
- 模板A：关键词 = `["蓝桥杯", "省赛"]`
- OCR文本：包含 "蓝桥杯" 和 "省赛"

**匹配过程**：
1. 模板A：关键词全部命中 ✅
2. 只有一个模板匹配
3. **直接返回模板A**

**结果**: 匹配成功 ✅

### 示例3：相似度匹配

**场景**：
- 所有模板的关键词都不完全匹配
- 模板B：样本文本与OCR文本相似度为 0.75
- 阈值 = 0.3

**匹配过程**：
1. 关键词匹配阶段：无匹配
2. 相似度匹配阶段：模板B得分 0.75
3. 0.75 >= 0.3，通过阈值检查
4. 竞赛名称验证：通过
5. **返回模板B**

**结果**: 匹配成功 ✅

## 七、配置说明

### 7.1 相似度阈值

配置文件：`backend/document_extract/config/type_matching_rules.json`

```json
{
  "award": {
    "similarity_threshold": 0.3
  }
}
```

### 7.2 文本清理规则

`_clean_text()` 函数会：
- 去除标点符号和特殊字符
- 去除空格、换行符、制表符
- 用于关键词匹配和相似度计算

---

## 八、注意事项

1. **关键词匹配优先级最高**：一旦关键词匹配成功，不再进行相似度匹配
2. **多模板匹配时选择关键词最多的**：确保更精确的模板被优先选择
3. **角色由模板决定**：匹配到模板后，使用模板的 `granted_role` 字段，而不是从OCR文本检测
4. **相似度匹配需要达到阈值**：低于阈值的模板不会被选择
5. **竞赛名称验证**：相似度匹配时会验证竞赛名称，但未匹配到竞赛名称时仍可能返回模板（可能是新竞赛）
