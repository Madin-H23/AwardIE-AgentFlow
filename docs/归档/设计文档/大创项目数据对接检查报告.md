# 大创项目数据对接检查报告

## 一、检查范围

1. 抽取器输出 → 数据库存储的字段映射
2. 数据保存逻辑（是否所有字段都保存）

## 二、发现的问题及修复

### 2.1 字段映射不完整

**问题**：
- 抽取器返回的 `project_number` 未映射到 `project_no`
- 抽取器返回的 `leader_student_id` 未正确映射
- `start_date` 和 `end_date` 格式不一致（YYYY.MM vs YYYY-MM）
- `members` 格式需要转换（从 `["姓名(学号)"]` 转为 JSON 格式）

**修复**：
- ✅ 在 `review_service._submit_innovation()` 中补充完整字段映射
- ✅ 添加 `_convert_members_format()` 方法处理成员格式转换
- ✅ 添加 `_normalize_date_format()` 方法统一日期格式
- ✅ 添加 `_convert_supervisors_format()` 方法处理教师格式
- ✅ 添加 `_get_leader_id()` 方法提取负责人学号

### 2.2 数据保存问题

**问题**：
- `other_members` 格式不统一，部分保存为字符串数组，部分为JSON
- 日期格式可能不一致

**修复**：
- ✅ 在 `add_project()` 和 `update_project()` 中统一 `other_members` 格式为JSON
- ✅ 确保日期格式统一为 YYYY-MM 或 YYYY-MM-DD

### 2.3 学生关联未恢复

**问题**：
- `_load_all_from_db()` 只加载主表数据，未加载学生关联
- 编辑页面和详情页面显示时，学生关联对象为空

**修复**：
- ✅ 添加 `load_project_with_associations()` 方法，加载项目时恢复学生关联
- ✅ 添加 `_load_associations_from_db()` 方法，从关联表恢复学生对象
- ✅ 在编辑页面和详情页面路由中调用 `load_project_with_associations()`

### 2.4 编辑页面显示问题

**问题**：
- `other_members` 显示为原始JSON字符串，用户无法编辑
- 日期字段使用 `type="date"`，但数据格式可能是 YYYY-MM

**修复**：
- ✅ 改进 `other_members` 显示：使用 textarea，每行一个成员
- ✅ 改进日期输入：使用文本输入，支持 YYYY-MM 格式
- ✅ 在编辑表单提交时，将文本格式的成员转换为JSON格式

### 2.5 详情页面显示问题

**问题**：
- 成员信息显示不友好（JSON字符串）

**修复**：
- ✅ 在详情页面路由中格式化成员显示
- ✅ 使用列表形式显示成员信息

## 三、数据流转路径验证

### 3.1 抽取器 → ReviewService

**抽取器输出**（`innovation.py`）：
```python
{
    "project_number": str,        # 项目编号
    "project_name": str,          # 项目名称
    "start_date": str,             # "2025-05" 或 "2025-06"
    "end_date": str,               # "2026-05" 或 "2026-06"
    "leader_name": str,            # 负责人姓名
    "leader_student_id": str,      # 负责人学号
    "members": List[str],          # ["张三(2022001)", "李四(2022002)"]
    "supervisors": List[str],      # ["王老师", "赵老师"]
    "project_level": str,          # "国家级"/"省级"/"院级"
    "acceptance_level": str,       # 验收等级（未存储）
    "project_description": str,    # 项目简介（未存储）
    "department": str              # 系别（未存储）
}
```

**ReviewService 处理**（`review_service.py`）：
- ✅ `project_number` → `project_no`
- ✅ `leader_name` → `student_leader_name`
- ✅ `leader_student_id` → `student_leader_id`
- ✅ `members` → `other_members` (JSON格式)
- ✅ `supervisors` → `supervisors` (逗号分隔字符串)
- ✅ `project_level` → `project_type`
- ✅ `start_date` / `end_date` 格式标准化
- ⚠️ `acceptance_level`、`project_description`、`department` 未存储（当前设计不存储）
