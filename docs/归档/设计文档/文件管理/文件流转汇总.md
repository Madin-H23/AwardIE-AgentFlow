# 文件流转汇总文档

本文档汇总奖状、专利、软著、其他、大创五类成果的文件流转逻辑，用于实现与测试。

---

## 1. 通用流程（阶段1-2）

所有类型统一：

### 1.1 阶段1：上传

| 项目 | 说明 |
|------|------|
| 入口 | `FileUploadService.upload_file()` |
| 存储 | `temp_upload/{session_id}/{hash}.{ext}` |
| 命名 | 按文件内容 MD5 hash + 扩展名 |

### 1.2 阶段2：提交审核

| 项目 | 说明 |
|------|------|
| 入口 | `PendingAchievementManager.submit_for_review()` |
| 移动 | `UnifiedFileManager.move_to_review(session_id, file_path)` |
| 源 | `temp_upload/{session_id}/{hash}.{ext}` |
| 目标 | `review/{session_id}/{hash}.{ext}` |

---

## 2. 阶段3：入库（按类型）

### 2.1 奖状（Award）

| 项目 | 说明 |
|------|------|
| 入口 | `ReviewService._submit_award()` |
| 移动 | `move_from_review_to_business(review_path, FileType.AWARD, image_hash)` |
| 目标 | `awards/{hash}.{ext}` |
| 命名 | hash 命名；目标已存在则直接覆盖 |
| 去重 | `_find_existing_award_in_memory(image_hash, cert_id)` |
| 特殊 | 若找到 existing 且 **hash 不同**（同奖状不同照片），先**删除旧文件**再保存新文件 |

### 2.2 专利（Patent）

| 项目 | 说明 |
|------|------|
| 入口 | `ReviewService._submit_patent()` |
| 移动 | `move_from_review_to_business(review_path, FileType.PATENT, image_hash=None)` |
| 目标 | `patents/patent_{timestamp}.{ext}` |
| 命名 | 时间戳命名 |
| 去重 | `_find_by_application_number(application_number)` |
| 特殊 | 若找到 existing 且 **证书路径不同**，先**删除旧文件**再更新 |

### 2.3 软著（Software）

| 项目 | 说明 |
|------|------|
| 入口 | `ReviewService._submit_software()` |
| 移动 | `move_from_review_to_business(review_path, FileType.SOFTWARE, image_hash=None)` |
| 目标 | `software/software_{timestamp}.{ext}` |
| 命名 | 时间戳命名 |
| 去重 | `_find_by_registration_number(registration_number)` |
| 特殊 | 若找到 existing 且 **证书路径不同**，先**删除旧文件**再更新 |

### 2.4 其他（Other）

| 项目 | 说明 |
|------|------|
| 入口 | `ReviewService._submit_other()` |
| 移动 | `move_from_review_to_business(review_path, FileType.OTHER, image_hash=None)` |
| 目标 | `other/{type}_{timestamp}.{ext}` |
| 命名 | 时间戳命名 |
| 去重 | `_find_by_hash(file_hash)`，hash 相同则返回 existing，不新增 |

### 2.5 大创（Innovation）

| 项目 | 说明 |
|------|------|
| 入口 | `ReviewService._submit_innovation()` |
| 文件 | 上传 xlsx，**不保留** |
| 操作 | 审核通过时**删除** `review/{session_id}/{hash}.xlsx` |
| 入库 | 仅写入 `innovation_projects` 表，无文件路径 |

## 3. 关键函数与 debug 节点

| 节点 | 函数 | 日志级别 | 内容示例 |
|------|------|----------|----------|
| 上传完成 | `FileUploadService.upload_file` | DEBUG | `[文件流转] 上传完成: {rel_path}` |
| 提交审核-移动 | `UnifiedFileManager.move_to_review` | DEBUG | `[文件流转] temp_upload->review: {src} -> {dst}` |
| 审核通过-移动 | `UnifiedFileManager.move_from_review_to_business` | DEBUG | `[文件流转] review->业务: {src} -> {dst}` |
| 奖状-删旧文件 | `AwardManager.add_award` | DEBUG | `[文件流转] 奖状删旧文件(hash不同): {path}` |
| 专利/软著-删旧文件 | `PatentManager` / `SoftwareCopyrightManager` | DEBUG | `[文件流转] 删旧证书(路径变更): {path}` |
| 大创-删文件 | `ReviewService._submit_innovation` | DEBUG | `[文件流转] 大创删除临时文件: {path}` |

---

## 4. 测试数据约定

- 测试根目录：`images/测试图片/`
- 子目录即类别：`奖状/`、`专利/`、`软著/`、`其他/`、`大创/`
- 每类选一个文件做流转测试；每步执行后校验 `files/` 下目录与预期一致。

---

## 5. 流转预期速查

| 类型 | 阶段1 | 阶段2 | 阶段3 |
|------|-------|-------|-------|
| 奖状 | `temp_upload/{sid}/{hash}.jpg` | `review/{sid}/{hash}.jpg` | `awards/{hash}.jpg` |
| 专利 | `temp_upload/{sid}/{hash}.ext` | `review/{sid}/{hash}.ext` | `patents/patent_{ts}.ext` |
| 软著 | `temp_upload/{sid}/{hash}.ext` | `review/{sid}/{hash}.ext` | `software/software_{ts}.ext` |
| 其他 | `temp_upload/{sid}/{hash}.ext` | `review/{sid}/{hash}.ext` | `other/other_{ts}.ext` |
| 大创 | `temp_upload/{sid}/{hash}.xlsx` | `review/{sid}/{hash}.xlsx` | **删除** |
