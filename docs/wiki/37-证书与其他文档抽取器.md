# 证书与其他文档抽取器

## 运行机制

证书与其他文档抽取器是抽取框架的末端策略节点。上层框架根据文件扩展名、关键词以及已注册的抽取器实例，选择调用某个 `Extractor.extract(ctx)`。本页面涉及的职责由两个抽取器共同承担：

- `CertificateExtractor`：证书类抽取器的基类，封装“OCR 文本获取 → 关键词预筛 → LLM 结构化抽取 → 响应解析 → 字段校验”
