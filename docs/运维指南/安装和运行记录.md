# 日常启动

## Windows（本机，2026-08 更新）

项目本体在中文路径，虚拟环境刻意放在英文路径：`D:\venvs\awardie`（Python 3.11）。

```
# 1. 进入项目目录
cd D:\Develop\AI 应用开发\AI应用开发项目\AwardIE-AgentFlow

# 2. 依赖安装（首次）
#    CPU 版依赖 + RAG 补装（requirements-cpu.txt 不含 RAG 三件套）
#    ⚠️ 本机有常驻代理时 pip 需先清空 HTTP_PROXY/HTTPS_PROXY 等变量
D:\venvs\awardie\Scripts\pip.exe install -r requirements-cpu.txt
D:\venvs\awardie\Scripts\pip.exe install chromadb langchain-chroma langchain-text-splitters

# 3. 启动（默认端口 5001；改端口用环境变量 PORT=）
D:\venvs\awardie\Scripts\python.exe run.py
```

访问 `http://127.0.0.1:5001`。测试账号：管理员 `admin`/`Mayy123`；教师工号 `02110606`（黄巧云）/`P@ss301`；学生学号 `212306413`（陈品天）/`P@ss301`。

**重启服务**：改 Python 代码（非模板）或直连改库后必须重启（dev server 只自动重载模板）。流程：`netstat -ano | grep :5001` 找 LISTENING PID → `taskkill //F //PID <pid>` → 后台重启 → `curl http://127.0.0.1:5001/login` 应 200。改 `.env` 后同样必须重启才生效（启动时 load_dotenv）。

**备份纪律**：全量回归跑完必须执行 `python scripts/restore_awards_history.py --apply` 还原业务数据（test_main_services/test_files 会清空真实库 awards/软著/pending）。每日自动备份在应用内由 log_scheduler 挂载（database/backups/ 时间戳目录），快照基线见 `database/snapshots/`。

## 设置自动启动



### 代码修改

```
sudo systemctl restart info-management
```

### 代码更新+重启

```
# 1. 进入项目目录
cd /home/ubuntu/csddata

# 2. 拉取最新代码（如果用 Git）
git pull

# 3. 如有依赖变更
source venv/bin/activate
pip install -r requirements.txt

# 4. 重启服务
sudo systemctl restart info-management

# 5. 确认运行正常
sudo systemctl status info-management
tail -f logs/app.log
```

### 部署

```
mkdir -p /home/ubuntu/csddata/logs
sudo nano /etc/systemd/system/info-management.service
```

内容：

```
[Unit]
Description=CSD成果管理
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu/csddata

# 保留系统 PATH，避免调用系统命令失败
Environment="PATH=/home/ubuntu/csddata/venv/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin"
Environment="PORT=5001"
Environment="FLASK_ENV=production"

ExecStart=/home/ubuntu/csddata/venv/bin/python run.py
Restart=always
RestartSec=3

StandardOutput=append:/home/ubuntu/csddata/logs/stdout.log
StandardError=append:/home/ubuntu/csddata/logs/stderr.log

[Install]
WantedBy=multi-user.target
```



```
# 3. 重载并启用
sudo systemctl daemon-reload
sudo systemctl enable csddata
sudo systemctl start csddata
sudo systemctl status csddata
```
