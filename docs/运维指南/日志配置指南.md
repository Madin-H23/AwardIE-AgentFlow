# 日志配置指南

## 概述

系统日志同时输出到控制台和文件，便于开发调试和生产环境问题排查。

## 日志文件位置

```
项目根目录/
├── logs/
│   ├── app.log          # 当前日志文件
│   ├── app.log.1        # 历史日志备份1
│   ├── app.log.2        # 历史日志备份2
│   ├── ...
│   └── app.log.5        # 历史日志备份5
```

## 日志轮转机制

- **单个文件大小限制**：10MB
- **备份文件数量**：保留最近 5 个
- **自动轮转**：当日志文件达到 10MB 时自动轮转

## 日志级别设置

日志级别从低到高：DEBUG < INFO < WARNING < ERROR < CRITICAL

### 设置方式（按优先级排序）

#### 1. 环境变量（最高优先级）

```bash
# Linux/Mac
export LOG_LEVEL=DEBUG
python run.py

# Windows (CMD)
set LOG_LEVEL=DEBUG
python run.py

# Windows (PowerShell)
$env:LOG_LEVEL="DEBUG"
python run.py
```

#### 2. .env 文件

在项目根目录创建 `.env` 文件：

```env
LOG_LEVEL=DEBUG
PORT=5001
FLASK_ENV=development
```

#### 3. settings.json 配置

编辑 `config/settings.json`：

```json
{
  "flask": {
    "log_level": "DEBUG",
    "debug": true
  }
}
```

### 推荐配置

| 环境 | 推荐级别 | 说明 |
|------|----------|------|
| 开发环境 | DEBUG | 显示详细调试信息 |
| 测试环境 | INFO | 常规运行信息 |
| 生产环境 | WARNING | 仅警告和错误 |

## 日志查看方法

### Linux/Mac

```bash
# 实时查看日志（推荐）
tail -f logs/app.log

# 查看最近 100 行
tail -n 100 logs/app.log

# 查看最近 500 行并翻页
less logs/app.log
# 按 G 跳到末尾，按 q 退出

# 搜索错误日志
grep ERROR logs/app.log

# 搜索今天的日志
grep "$(date +%Y-%m-%d)" logs/app.log

# 搜索特定关键词
grep "laboratory_id" logs/app.log

# 统计错误数量
grep -c ERROR logs/app.log

# 查看最近 1 小时的日志
find logs/app.log -mmin -60 -exec cat {} \;

# 持续监控并过滤关键字
tail -f logs/app.log | grep --line-buffered "ERROR"
```

### Windows PowerShell

```powershell
# 实时查看日志
Get-Content logs\app.log -Wait -Tail 50

# 查看最后 100 行
Get-Content logs\app.log -Tail 100

# 搜索错误
Select-String -Path logs\app.log -Pattern "ERROR"

# 搜索特定关键词
Select-String -Path logs\app.log -Pattern "laboratory_id"
```

### Windows CMD

```cmd
# 查看最后 100 行
powershell -Command "Get-Content logs\app.log -Tail 100"

# 搜索错误
findstr "ERROR" logs\app.log
```

### 通用方法（跨平台）

使用 Python 脚本查看日志：

```python
# view_log.py
import sys
from pathlib import Path

log_file = Path("logs/app.log")

# 查看最后 N 行
def tail(n=100):
    with open(log_file, 'r', encoding='utf-8') as f:
        lines = f.readlines()
        for line in lines[-n:]:
            print(line, end='')

# 搜索关键字
def grep(keyword):
    with open(log_file, 'r', encoding='utf-8') as f:
        for line in f:
            if keyword in line:
                print(line, end='')

if __name__ == '__main__':
    if len(sys.argv) > 1:
        grep(sys.argv[1])
    else:
        tail()
```

使用方式：
```bash
python view_log.py           # 查看最后100行
python view_log.py ERROR     # 搜索 ERROR
python view_log.py laboratory_id  # 搜索特定字段
```

## 常见日志分析场景

### 1. 查看特定奖状的保存过程

```bash
grep "award_id=804" logs/app.log
```

### 2. 查看实验室相关操作

```bash
grep "laboratory_id" logs/app.log
```

### 3. 查看所有错误日志

```bash
grep ERROR logs/app.log
```

### 4. 查看最近的异常

```bash
grep -A 10 "Traceback" logs/app.log | tail -50
```

### 5. 统计各类型日志数量

```bash
echo "INFO: $(grep -c INFO logs/app.log)"
echo "WARNING: $(grep -c WARNING logs/app.log)"
echo "ERROR: $(grep -c ERROR logs/app.log)"
```

## 生产环境日志管理

### 使用 logrotate（Linux）

创建 `/etc/logrotate.d/competition-system`：

```
/path/to/project/logs/app.log {
    daily
    rotate 30
    compress
    delaycompress
    missingok
    notifempty
    create 644 www-data www-data
    maxsize 100M
}
```

### 远程日志收集（可选）

集成第三方日志服务：

- **Sentry**：错误追踪和性能监控
- **ELK Stack**：Elasticsearch + Logstash + Kibana
- **Loki**：轻量级日志聚合系统

### 日志清理脚本

创建 `tools/clean_logs.sh`：

```bash
#!/bin/bash
# 清理超过 30 天的日志备份

find logs/ -name "app.log.*" -mtime +30 -delete

echo "日志清理完成: $(date)"
```

添加到 crontab：

```bash
# 每周日凌晨 2 点执行
0 2 * * 0 /path/to/project/tools/clean_logs.sh
```

## 故障排查

### 问题1：日志文件没有生成

**可能原因**：
- logs 目录没有写入权限
- 磁盘空间不足

**解决方法**：
```bash
# 检查权限
ls -la logs/

# 修复权限
chmod 755 logs/

# 检查磁盘空间
df -h
```

### 问题2：日志文件过大

**可能原因**：
- DEBUG 级别在生产环境使用
- 日志输出过于频繁

**解决方法**：
```bash
# 将日志级别改为 INFO 或 WARNING
export LOG_LEVEL=WARNING
```

### 问题3：日志乱码

**可能原因**：
- 文件编码问题

**解决方法**：
```bash
# 查看时指定编码
iconv -f GBK -t UTF-8 logs/app.log
```

## 监控告警（可选）

### 使用 monit 监控日志

创建 `/etc/monit/conf.d/log-monitor`：

```
check file log_file with path /path/to/logs/app.log
    if size > 100 MB then alert
    if match "ERROR" then alert
```

### 定期检查脚本

```bash
#!/bin/bash
# 每小时检查错误数量

ERROR_COUNT=$(grep -c "ERROR" logs/app.log)
if [ $ERROR_COUNT -gt 100 ]; then
    echo "警告：最近一小时有 $ERROR_COUNT 个错误" | mail -s "系统告警" admin@example.com
fi
```
