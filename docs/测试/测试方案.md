# 管理员

以下其他动作都是在管理员登录的情况下完成的

管理员帐号admin，密码

以下测试内容互相存在关联，如果有一个错误，就先暂停不再继续测试直到错误解决为止。

## 测试准备

1. 清空奖状：点击成果管理，勾选包含教师证书，选中所有的奖状，点击批量删除，点击确定。可以将所有的奖状清空。
2. 清空未审核成果：点击成果审核，点击全部放弃
3. 清空文件：删除files/temp_upload 和files/review 下面的所有文件。
