# 大创项目状态管理(管理员日常操作)

> 适用角色:系统管理员 | 相关页面:成果管理(成果库)→ 大创管理 tab、大创项目编辑页

## 一、状态的三个值

大创项目的 `状态` 只有三种取值,含义如下:

| 状态 | 含义 |
|---|---|
| **进行中** | 项目尚未结束(默认值:新建、xlsx 批量导入未指定状态时都是它) |
| **已结题** | 项目已正常完成结题 |
| **终止** | 项目中止(未结题) |

## 二、两种维护方式

### 方式 1:单个项目改状态(精确)

进入 **成果管理(成果库)→ 大创管理**,对某行使用**详情编辑**(或从列表进入编辑页),在「项目状态」下拉中选择 `进行中 / 已结题 / 终止`,保存即生效。适合零散、个别的调整。

### 方式 2:批量校准(按结束日期)

项目扎堆到期时,逐条改不现实。大创管理 tab 的筛选栏有 **「状态校准」** 按钮:

- **做什么**:把所有**结束日期已过**、且状态仍为「进行中」的项目,一次性标记为「已结题」;
- **不碰什么**:`终止`、`已结题` 的项目不动;结束日期在未来或当天的项目不动;没有填结束日期的项目不动;
- **可重复点**:重复点击是安全的(第二次会提示「已校准 0 条」),每次操作都会记入系统日志(操作人、校准条数)。

**建议节奏**:每学期末/学年初对一次;或每次 xlsx 批量导入历史项目后点一次(导入默认全部是「进行中」,已结束的历史项目需要校准)。

## 三、常见问题

**Q:导入的历史项目为什么全是「进行中」?**
xlsx 模板没有「状态」列,导入统一按默认值「进行中」写入。已结束的项目请在导入后点一次「状态校准」,或在编辑页逐条改。

**Q:结束日期格式很乱(2025-06、2024.5.1、2025年6月)会影响校准吗?**
不会。校准功能兼容这几种常见格式;遇到无法识别的日期会跳过该项目并在结果消息里提示「N 条日期无法识别未处理」——请人工进编辑页修正该项目的结束日期后重点一次。

**Q:今天到期的项目会被校准吗?**
不会。判定线是「结束日期严格早于今天」,当天是项目的最后一天,仍算进行中;次日起再点校准即可标为已结题。
