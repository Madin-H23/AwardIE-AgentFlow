# 数据分析与导出功能使用说明

## 功能概述

数据分析与导出功能提供竞赛数据的可视化分析，支持管理员和实验室两种数据范围。

## 访问入口

### 管理员
- 路径：`/admin/data-analysis`
- 权限：管理员账号
- 数据范围：全部数据

### 实验室
- 路径：`/laboratory/<lab_id>/data-analysis`
- 权限：实验室成员（指导教师、助理）
- 数据范围：本实验室数据

## 功能说明

### Tab 1: 竞赛信息

**图表：** 时间点标记图（散点图）

- **蓝色圆点**：报名开始月份
- **橙色圆点**：比赛时间（中点月份）
- **绿色圆点**：出奖时间月份

**表格：** 竞赛详情
- 竞赛名称
- 时间范围（原始格式）
- 官网链接（新窗口打开）
- 白名单状态

### Tab 2: 竞赛分析

**使用步骤：**
1. 在左侧下拉框选择竞赛
2. 右侧自动显示三个图表：
   - **竞赛贡献度**：该竞赛的奖状数量
   - **历年获奖趋势**：按年份统计的奖状数量变化
   - **奖状月度分布**：奖状在各月份的分布热力图

### Tab 3: 获奖数据分析（动态可视化）

**控制面板（左侧）：**

1. **X轴选择**
   - 年份：按年份统计
   - 实验室：按实验室统计
   - 教师：按指导教师统计

2. **颜色分组**
   - 实验室：按实验室区分颜色
   - 年份：按年份区分颜色
   - 竞赛等级：按A类/B类/C类区分颜色

3. **图表类型**
   - 柱状图：常规柱状图
   - 堆叠柱状图：堆叠显示
   - 分组柱状图：分组显示
   - 折线图：趋势线

**限制规则：**
- X轴和颜色分组不能选择相同的维度
- 例如：不能同时选择"年份"作为X轴和颜色分组

## 筛选条件

### 全局筛选（所有Tab共享）
- **年份范围**：多选下拉框，可选择多个年份
- **白名单赛事**：勾选框，仅显示白名单中的竞赛

### 动态筛选（Tab 3）
- **年份筛选**：当X轴和颜色分组都不是"年份"时显示
- **实验室筛选**：当X轴和颜色分组都不是"实验室"时显示

## 使用技巧

### 快速分析常用场景

1. **查看每年国赛省赛变化**
   - Tab 3
   - X轴：年份
   - 颜色分组：竞赛等级
   - 图表类型：堆叠柱状图

2. **查看实验室产出对比**
   - Tab 3
   - X轴：实验室
   - 颜色分组：年份
   - 图表类型：柱状图

3. **查看某个竞赛的历年获奖情况**
   - Tab 2
   - 选择竞赛
   - 查看"历年获奖趋势"图

4. **查看竞赛时间分布**
   - Tab 1
   - 查看"竞赛时间分布"图
   - 识别报名、比赛、出奖月份

## 数据更新

- 所有图表实时从数据库读取最新数据
- 修改筛选条件后自动刷新
- 无需手动刷新页面

## 常见问题

**Q: 为什么某些竞赛没有时间点？**
A: 这些竞赛在数据库中没有记录时间信息，仅显示在表格中，不在图表中。

**Q: 如何导出数据？**
A: 当前版本仅提供可视化分析，数据导出功能将在后续版本中添加。

**Q: 实验室和管理员看到的数据有什么区别？**
A: 实验室只能看到本实验室的奖状数据，管理员可以看到全部数据。
