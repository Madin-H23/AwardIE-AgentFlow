## 诊断精确化(实读取证)

读 AdminDashboardView 全文后,B4"259 重复"实为**三重重复 + 一处语义 bug**:

1. 汇总卡左栏大数字 = grandTotal,与资产卡"成果总数"**同值同屏**;
2. 且该卡 label 写"本周期成果新增(2026 年至今)"而值是**全量总数**——名实不符(语义 bug,v1 对照遗留);
3. 资产卡"成果总数"副文案塞五类分类小字,与汇总卡右栏"分类计数"**再次重复**;
4. "待审核/白名单"也在汇总卡小字三度出现。

## 方案:每个数据只有一个家(信息分层)

| 数据 | 唯一归属 |
|---|---|
| 全量总数 259 | 资产卡"成果总数"(sub 改口径说明"分类明细见下方汇总卡") |
| 本月新增 + 环比 | 汇总卡左栏大数字(compare.this,label 改"本月新增",名实相符;sub=上月 N · 环比 ▲/▼%) |
| 分类计数五项 | 汇总卡右栏(唯一处) |
| 待审核/白名单竞赛 | 资产卡(汇总卡小字删除) |
