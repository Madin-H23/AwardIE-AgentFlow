# UX-1 批2:工作台卡片化重做(三段文档 01)

> 归属:`../../00-诊断与方案.md` 五批拆分之批 2;消灭诊断项 B1(工作台裸链接=全站最大丑点)。

## 关键定性(实读取证)

- HomeView 在守卫(router.beforeEach)下是 **admin 专属工作台**:student/teacher 访问 `/` 被重定向至各自门户仪表板——原页面"提交奖状(学生)/教师审核台(教师)"的分组对本页实际用户无意义,重做按 admin 视角设计。
- 入口**与侧边栏同源**:路径与文案照抄 ConsoleLayout 菜单配置(含此前发现的导航/页内标题错位,如"成果管理"→/admin/achievements 而 /admin/awards 页内标题才是"成果管理"——错位治理记批 3)。
- 速览条复用 #28 `GET /api/v2/admin/stats/overview` 聚合(summary.totalAwards/pendingSubmit/competitions/whitelist 四键),**零后端改动**;失败静默不阻塞入口主链。

## 设计

- 页头:PageHeader(批 1 组件首批实战)+ actions(个人资料/登出,登出 danger plain 突出)。
- 速览条:4 数字卡;`pendingSubmit > 0` 时数字转 `--tag-warning` 警示并附"需处理"——把"积压"从埋在 dashboard 里提升为进门第一眼。
- 入口分组卡:四组(审核与成果/数据洞察/基础数据/AI 与工具)auto-fill 网格,每卡 icon+标题+一句话描述;hover border 变 brand+上移 1px(与路由过渡同 150ms 语言);reduced-motion 豁免。
- 审校自查:无营销化装饰、无新增色板/字体,大胆预算仍全部花在"页面节奏"签名上;卡片 hover 是唯一微交互。

## 测试计划

- E2E 首页用例同步改写(业务入口/管理端(admin) 裸链接断言 → 分组词+entry-card 断言)。
- lint/build/E2E 全量+实景走查(卡片数/速览数/console)。
