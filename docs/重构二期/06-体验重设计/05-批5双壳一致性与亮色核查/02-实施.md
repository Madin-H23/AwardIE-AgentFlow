## 实证修正:hover 桥接的探针证伪与前会话初版的差异

初版(前会话)在 `:root` 桥接段加 `--el-table-row-hover-bg-color: var(--sb-hover)`,本会话按 handoff 遗留疑问("html.dark 优先级可能盖 :root 桥接")用一次性 Playwright 探针实测,**结论推翻了初版假设**:

1. **`:root` 桥接是死代码**:EP 在 `.el-table` 元素自身定义了同名变量(元素级定义永远压过 `:root` 继承),console 表另被 tokens.css L333 `.console-shell .console-main .el-table` 作用域规则接管——`:root` 值到不了任何真实元素,已删除(tokens.css 净改动归零);
2. **暗色 hover 无 bug**(handoff 担忧证伪):console 表亮/暗 hover 均为品牌蓝 5%(color-mix);portal 表亮 `#f5f7fa` / 暗 `#262727`(EP 各自主题库存值,亮暗成立;portal 橙色体系不宜刷品牌蓝,维持 EP 库存正确);
3. **E2E 断言虚设修正**:初版断言读 `tr` 背景恒为面板白(永真,结构层断言盲区再现),改为读 `td` hover 前后对比(可证伪:hover 坏则 before=after 用例红);
4. **重绘验证补强为真交互**:初版 localStorage+reload 不走 watch,改为点击顶栏 `theme-toggle` 不刷新切主题,断言 canvas 重新可见(dispose+重建链路)。

## 本批踩坑

- **EP 组件变量定义在元素级**:`.el-table { --el-table-row-hover-bg-color: … }` 写在组件 css 上,任何 `:root`/`html.dark` 层桥接都到不了 el-table——要定制 hover 必须挂在 `.el-table` 或其祖先作用域上;
- **hover 色在 td 不在 tr**:EP 的 `tr:hover > td` 规则把背景刷到 td,tr 自身恒为 `--el-fill-color-blank`,读 tr 断言 hover 是恒真陷阱;
- `getComputedStyle` 对 `color-mix()` 返回 `color(srgb …)` 形式,与 `rgb()` 字符串比较时注意(本批只比 before/after 不同,回避了格式比较)。
