## 三件事

### ① TemplatesCreateView 主链接入

创建模板页此前"AI 抽取/提示词生成走架构票(fake),字段管理以 JSON 编辑区先行",底部面板为占位文案。方案接通两条主链(对照 v1 create 页):

- **AI 抽取**:上传样本图 → `POST /admin/templates/extract-for-create`(multipart)→ 回填样本抽取值(dataJson 美化)与样本文本(留空时填 ocrText);
- **生成提示词**:当前表单规则 → `POST /admin/templates/generate-prompt-for-create`(JSON:keywords/sample_extracted/default_fields/llm_fields/min_length/max_length/language/need_translate/sample_text)→ 只读预览区展示 prompt;
- 两处均展示 mode(fake/grpc)tag;save() 的 fetch+XSRF 逻辑抽为 postForm 复用。

### ② test 端点 grpc 路径(后端)

`POST /admin/templates/{id}/test` 此前 grpc 模式直接 4003"待接入"。方案:读 `sample_image_blob`(BYTEA→byte[])→ `aiClient.extractTemplate(img, "sample.png", "{}", …)`(Worker 端 ExtractTemplate 当前消费固定 award 抽取器,template_rule_json 为预留字段,故传 "{}" 与 extract-for-create 同契约)→ 返回键名契约不变(mode/fields/ocrText)。无样本图显式 4000。

### ③ GeneratePrompt 4000 友好码(Worker,架构票实施批 Low 挂账销账)

`ai_worker/server.py` GeneratePrompt:min_length/max_length 非数值时 `int()` 抛 ValueError 落 5000;改为捕获 TypeError/ValueError 收敛 4000"模板规则数值非法"。
