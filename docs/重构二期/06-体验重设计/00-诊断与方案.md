## 二、设计方向(先审校,再动刀)

定位:高校成果管理的**内部专业工具**——设计目标是"秩序感+可信+高效",不是营销页的惊艳。因此:**不引入新色板/新字体**(现有 tokens.css 暗亮双主题与 portal orange 体系是资产),把大胆预算花在**"统一页面节奏"这个签名元素**上:每页固定"页头 → 内容卡 → 反馈"三段式 + 150ms 路由过渡 + 骨架屏,让 33 个页面拥有同一呼吸节奏。这是内部工具最该被记住的一件事。

Token 演进(在现有 tokens.css 上补齐,不重写):
- **色**:沿用 --brand/--panel/--ink 体系;补语义徽章浅底四色(success/warning/danger/info 的 bg+border 变体,暗亮双份)。
- **型**:系统字体栈不变;数据列启用 `font-variant-numeric: tabular-nums`;定 type scale(页头 1.15rem/600、区块题 1rem/600、辅助 0.78rem/--ink-2)。
- **布局**:统一 PageHeader 组件(标题+副标题+操作区右对齐);间距 8pt 网格;列表页筛选区收进可折叠卡。
- **动效**:路由过渡 150ms fade(尊重 prefers-reduced-motion);表格行 hover 底色;按钮/卡片现有 EP 语言保留。
