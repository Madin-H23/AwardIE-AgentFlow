# UX-2 批6:挂账小批(三段文档 01)

> 归属:UX-1 批 5 范围决议明确"不硬做、收官后另立小批"的三项挂账 + 批 5 OCR Low 挂账,合并为一批收官。

## 三件事

### ① 筛选折叠(B5 诊断销账)

待审管理是全站唯一十维筛选页(审核域三维:关键词/类型/状态 + jsonb 六维 + 时间维)。方案:默认只露审核域三维 + "展开更多筛选"开关,七维高级筛选 `v-if` 折叠;查询/重置常驻。单一页面即全量(B5 诊断只此一处,其余列表页筛选 ≤4 维不折叠)。

### ② 徽章化与 .num 推广(B2/B3 收尾)

盘点 16 个含表格视图后,存量英文直出与未对齐数字列:

- **状态列徽章化(3 处)**:StudentSubmitView / StudentDashboardView / StudentAchievementsView 的 `prop="status"` 裸列 → statusLabel/statusTagType tag(批 3 只做了 admin 两页示范);
- **提交者类型中文化(2 处)**:AdminAwardsView 与 TeacherReviewView 的 student/teacher 直出(批 3 漏网,批 5 亮色截图可见)→ useBadge 新增 SUBMITTER_TYPE_LABELS(student→学生/teacher→教师/admin→管理员);
- **TeacherReviewView 类型列**:`prop="achievementType"` 裸列(award/patent 直出,批 3 漏网)→ typeLabel tag;
- **类型下拉中文化**:AdminAwardsView 筛选"类型"下拉 `:label="t"` 直出英文 → typeLabel;
- **.num 等宽推广(14 列)**:7 个视图的 ID/年份列加 `class-name="num"`(AdminCompetitions/AdminAchievements×5+year/AdminTemplates/StudentAchievements×2/StudentSubmit×2/StudentDashboard×2/LabDownloads);
- **显式不做**:AdminAchievementsView 大创 tab 的 status 列是**业务状态**(进行中等中文值),非审核状态,不套审核徽章;patent_type/project_type 等本就是中文业务值,不动。

### ③ analysis 双页主题切换重绘(批 5 OCR Low 销账)

AdminDataAnalysisView / LabDataAnalysisView 图色渲染时读 tokens 但无 theme watch,切主题后图色停留。方案:与 AdminDashboardView 同模式 `useTheme` + watch,按各自 activeTab 既有分发重建(renderTab1/loadTab2/renderTab3;renderContrib/renderHeat)。
