# UX-1 批1:全局交互地基(三段文档 01)

> 归属:`../00-诊断与方案.md` 五批拆分之批 1;消灭诊断项 A1/A5/B7。范围声明:**批 1 只建机制与组件+单页示范,全量页面接入分别在批 2(工作台)/批 3(列表页族)顺带完成**——避免一批动 33 页造成回归面失控。

## 方案

| 项 | 决策 |
|---|---|
| 路由过渡 | 两壳(ConsoleLayout/PortalLayout)router-view 包 `<transition name="page-fade" mode="out-in">`,150ms fade+4px 上移入;key=route.path(非 fullPath:query 变化如 coming-soon?title= 不触发重过渡);`prefers-reduced-motion: reduce` 下禁用(质量底线) |
| 语义徽章色 | tokens.css 补 `--tag-success/warning/danger/info` 的 fg+bg 双值,**亮暗成对**;与日志 `--sev-*` 命名隔离(语义不同,未来可独立调);供批 3 状态/类型徽章化消费 |
| type scale | `--fs-page`(1.15rem 页头)/`--fs-section`(区块题)/`--fs-cap`(辅助文案);数据列等宽工具类 `.num { font-variant-numeric: tabular-nums }` |
| PageHeader 组件 | props title/subtitle + #actions 插槽;签名元素"页头→内容卡→反馈"三段式的第一段;手动 import(项目无自定义组件自动注册惯例) |
| TableSkeleton 组件 | el-skeleton 包装(rows 可配);批 3 接入列表页替换 v-loading 裸转圈 |
| 示范接入 | AdminCompetitionsView 裸 h2 → PageHeader(唯一页面改动;E2E heading 断言 h2→h1 仍命中) |

## 审校自查(frontend-design 流程)

- 不换色板/字体:现有 tokens 暗亮体系与 portal orange 是迁移资产,推倒重来违反"秩序感"定位 ✓
- 大胆预算集中在"页面节奏"一处,不动 Element Plus 组件语言,不加装饰性动效 ✓
- 过渡 150ms+位移 4px:低于可感知干扰阈值,不产生"动画感" ✓
