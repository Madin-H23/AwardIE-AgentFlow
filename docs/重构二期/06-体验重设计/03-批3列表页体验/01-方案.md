# UX-1 批3:列表页体验 + 工作台入口修复(三段文档 01)

> 归属:`../../00-诊断与方案.md` 五批拆分之批 3;消灭诊断项 A3/B2/B3;**插播修复:用户实测反馈"工作台没有入口,只在登录 admin 时跳转一次"**。

## 修复项:工作台无入口(用户实测 bug)

- **取证**:ConsoleLayout 侧边栏唯一固定项(overview)= "数据总览"(/admin/dashboard),整个 admin 侧边栏无指向 `/`(工作台)的入口;portal 侧有"教师首页/学生首页"(House),console 侧缺失。
- **修法**:overview 固定项改为 `工作台`(House,path '/'),"数据总览"挪入"用户数据"组首项——与 portal 侧"XX首页"体系对齐,固定项=回家的路。

## 主体改动(诊断 A3/B2/B3)

| 项 | 方案 |
|---|---|
| 中文徽章化(B2) | 新建 `composables/useBadge.ts` 单一真源:类型(award→奖状/…)+状态(pending→待审/archived→已归档/rejected→已驳回)+statusTagType 映射;消费批 1 `--tag-*` 语义色 |
| Fix-V 模式推广(A3) | AdminAwardsView 操作列:disabled 按钮(诱导点击)→ pending 行才渲染按钮组+已审行显示状态 tag(与教师审核台同构) |

## 明确不做(与挂账)

- 筛选区折叠(B5):AdminAwardsView 十维筛选信息密度高,折叠交互值得单独设计,**挂账**不硬做。
- 表格行 hover(A4):Element Plus 自带 hover 底色,暗色下对比度问题待批 5 亮暗核查统一处理。
- 其余列表页(student submit/achievements 等)徽章化推广:挂账(待审管理为最高频入口,先行)。
