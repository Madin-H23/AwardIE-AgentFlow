## 四、踩坑

- `rest.execute` 第三参是 `RequestCallback` 而非 `HttpEntity`——传错=头部静默丢失(4010),GET+SSE 短流直接用 `exchange(..., String.class)` 更稳;
- python 生成 Java 字面量时 `\"` 经 shell 层剥转义,jsonb CAST 的引号全丢——**转义敏感内容用 Edit 工具直改,不走 python -c**。
