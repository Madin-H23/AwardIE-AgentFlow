## 二、测试中发现并修复的三个自身缺陷

1. **参数表错位**:首版 `args` 固定按「带 year」组装,year 为 null 时 SQL 只有 3 个占位符
   → `Parameter index out of range (4 > 3)`。修:参数列表按 year 是否存在动态组装。
2. **权限挂错**:`my-affairs.csv` 最初挂 `business:vault:query`,实测学生 403——
   **这反而是正确方向**:学生没有也不该有 vault:query(给了即新造 D-04 式越权)。
   改挂 `pending-achievement:query`(学生三权限之一),越权由 SQL 内
   `student_id = 当前登录人` 双保险。验证:学生拿到本人 4+ 行明细。
3. **TS 残留**:教师页重写后 `rows` 引用与孤儿 import 残留,ts:check 抓出(TS2339/TS6133),已清。
