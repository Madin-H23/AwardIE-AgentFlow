## 两条偏差声明(评估后不搬,防重复建设)

1. **useBadge 不整搬**:v3 各列表页已有自己的中文标签助手(kindLabel/statusTone 等,批10-20 逐步落的地
   本地实现),整包搬入=两套映射并存。v2 的 useBadge 本质是"集中映射",v3 的分散实现在等价能力面上。
2. **筛选折叠=幻账不搬**(validation-rules 先例):v2 折叠服务的是 7+ 项大筛选表单;
   实测 v3 全部 11 个列表页筛选表单只有 **2-5 项**(logs 5 项最大),折叠无用武之地。
