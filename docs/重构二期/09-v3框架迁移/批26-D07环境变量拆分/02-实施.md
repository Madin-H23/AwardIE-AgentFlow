## 结果:一个变量一种含义

新契约(D-07 验收口径):

| 变量 | 唯一含义 | 消费方 |
|---|---|---|
| `AWARDIE_MYSQL_PASSWORD` | **应用账号 awardie_v3 的口令** | Spring 数据源、`mvn test`(CI=ci-test-pass)、ETL 五件套、run_awardie_sql、apply 的非 root 分支 |
| `AWARDIE_MYSQL_ROOT_PASSWORD`(新) | **root 口令** | reconcile / schema_diff / prune_dead_menus 的默认 root 连接、apply 的 `AWARDIE_MYSQL_USER=root` 分支(CI)、rehearsal 的建库链 |

**规则统一为"口令跟账号走"**:三件工具(reconcile/schema_diff/prune)默认 root 但保留
`AWARDIE_MYSQL_USER` 覆盖口,口令按 `user == 'root'` 二选一——写死 root 变量的首版
**被 rehearsal 的对账层当场抓住**(演练链以专用账号调 reconcile,却拿到 root 口令被拒),
这正是演练闸门存在的意义。apply 早已是同款双分支,本次只是把规则推广成全局一致。
