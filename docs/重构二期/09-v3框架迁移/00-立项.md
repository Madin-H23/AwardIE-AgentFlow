## 一、目标与边界

- **目标**:以芋道 ruoyi-vue-pro(master-jdk17 分支)为底座重建 v3,替代 v2 自建栈;系统层(用户/角色/菜单/权限/日志/字典/代码生成/文件存储)直接用芋道,业务域按芋道模块规范逐批移植;
- **不变**:Python AI Worker(百度 OCR+LLM+RAG+gRPC 契约)原样保留,v3 以 gRPC 客户端对接;v2 现状继续作为生产参考实现,切流前不停;
- **范围外**:业务语义不借债——v2 已清偿的行为(如大创 status 方向1+2)在 v3 对应批次必须等价实现,不允许"框架自带就行"的静默降级。

## 四、验收指标(总)

1. 每批出口条件全达成+三段文档+该批测试全绿+OCR 0 High/Critical;
2. 终态:三角色全链路(提交→初审→复核→入库→统计)在 v3 跑通,v2 等价功能逐项对照无静默降级;
3. 数据迁移后对账:v2 PG 各业务表行数与 v3 MySQL 一致(允许字段映射差);
4. CI(v3 仓库)五门禁等价绿:lint/raw-controls/jdbc-audit/build/后端测试+E2E;
5. 切流前双跑窗口期≥1 周,v2 保持可回滚。
