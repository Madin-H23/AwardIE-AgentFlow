# 03 — 模板域 CRUD + 删除 + 样本图回显

**What to build:** 按芋道分层建立模板域(DO + Mapper + Service + Controller + VO),交付五个端点:分页列表(竞赛与授予角色双维过滤)、创建(multipart 样本图 + 竞赛 + 授予角色 + 规则字段)、详情、编辑、样本图字节回显;外加一个逻辑删除端点。样本图复用批4 的文件域服务(三校验 + 内容寻址去重),不新建存储。业务规则:同竞赛 + 同授予角色 + 未删除只允许一个模板(冲突抛业务码);`granted_role` 只接受"学生"/"教师";创建时校验竞赛存在;规则字段 JSON 非法在进服务前被拒(不让驱动层 500);编辑只接受语言、长度区间、关键词、样本文本、默认字段、LLM 字段、是否翻译,`granted_role` 与 `competition_id` 不在白名单(v2 能改默认字段绕过唯一性,是缺陷不是语义,明确修掉)。JSON 字段出入参为结构化对象而非 JSON 字符串(修 v2 前后端契约错位)。删除为逻辑删除且同流程回收样本图物理文件(回收前的引用检查在 T04 落地,本票先接好调用位)。教师与学生访问全部端点 403。
