# 04 — 模板域 AI 三端点(试测/创建前抽取/生成 prompt)

**What to build:** 交付模板域的三个 AI 端点:保存后试测(用样本图跑 `ExtractTemplate`,返回抽取字段与 OCR 文本)、创建前抽取(还没建模板时先验证样本图)、生成 prompt(按模板规则跑 `GeneratePrompt`,返回 prompt 与免责声明)。fake 模式走确定性桩(离线可开发可演示),grpc 模式调真 Worker;两者共用 T02 建好的客户端与模式开关,沿用 T03 模板域的权限点(归 query,不单开 AI 权限点)。错误处理与 Worker 契约对齐:业务码在响应体 `code` 内,`4000` 规则非法 / `4003` AI 依赖不可用 / `4004` 图片不可读或抽取失败 / `5xxx` 内部错误原样透传,传输层异常映射 4003;Worker 不可用时返回明确业务错误,**不 500、不挂死**。模板无样本图时试测给出明确错误。三个端点均**不得在测试中依赖真 Worker 在线**。
