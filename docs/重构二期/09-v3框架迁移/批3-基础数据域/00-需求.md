## 三、需求条目

### R1 竞赛域 CRUD(全字段)

- 表 `awardie_competitions` 按 F1 落 11 业务字段 + 芋道标准审计/逻辑删除/租户列;
- API 用 codegen 标准 CRUD(create/update/delete/delete-list/get/page/export-excel)+ **全字段**覆盖 v2 两个控制器的并集;
- 保留 v2 语义:名称必填 + **重名拒绝**(v2 前置查询 4009);唯一性只由 service 层保证,**不加 DB 唯一索引**(逻辑删除下已删同名会永久占位,且与 @TableLogic 查询语义打架,详见 01-spec);`is_auto_added` 只读(建档时 false,v2 同);
- 白名单/观察名单 = 普通 boolean 字段,v2 的"只切名单"PUT 在 v3 由 update 全字段承载(前端批10 适配,不再单开端点)。

### R2 实验室域补全为 v2 等价 CRUD

- 现有切片已是标准 CRUD,本批补:①引用检查(见 R3)②名称唯一性校验(v2 无 DB 约束但语义上按名称识别,重复名会污染 `SELECT id WHERE name=?` 的取值——v3 显式拒绝)③详情聚合端点(教师/学生/下载数/成果数)与下载列表端点:依赖 laboratory_instructors/students/downloads 三张关联表,这三张表属实验室成员/文件域,**归批4**(见范围边界);
- 保留批1 已有 page 关键词(name LIKE)、逻辑删除、租户隔离。

### R3 删除前引用检查(决策 D1:骨架本批建、成果表到位后自动生效)

- service 层在 delete 前做**显式引用检查**(不再依赖 DB 外键异常——v3 逻辑删除下 FK 根本不会触发,沿用 v2 靠 FK 的做法在 v3 是死代码);
- 实现口径:一张**可引用表清单**(竞赛→awards/templates;实验室→awards/patents/software_copyrights/innovation_projects/other_files + 实验室关联表),逐表 `SELECT COUNT(*) ... WHERE <fk>=?`,**表不存在则跳过**(F9:本批成果表还没建),**存在且 count>0 则拒绝**并返回业务错误码;
- 拒绝信息带出被引用的表与行数(v2 只说"存在关联成果",v3 给出可诊断信息);
- 逻辑删除的引用行不计入(引用行 deleted=1 视为已删,不阻断)——与 v3 逻辑删除语义一致。

### R4 权限与菜单

- 两域权限点 `business:competitions:*` / `business:laboratories:*`(create/update/delete/query/export),菜单固定 ID 幂等 SQL,授予 awardie_admin(批2 角色 id=100)与 super_admin;
- 批1 的 laboratories 菜单已存在,本批只追加 competitions 菜单与角色授权。

### R5 数据 ETL(决策 D2:带脚本并实跑 dev 库)

- `scripts/etl_v2_competitions_laboratories_to_v3.py`(仿批2 ETL 形态):PG competitions 218 + laboratories 5 → v3 dev 库,**显式保 v2 id**(为批12 外键迁移铺路),`ON DUPLICATE KEY UPDATE` 幂等,末尾抬 AUTO_INCREMENT,输出行数/id 集合差/二跑幂等三项校验;
- v2 布尔 → v3 BIT(1);alias_list/competition_time 等文本原样迁;laboratories.cover_image 属批4 文件域,**不迁**(记录在文档);
- dev 库既有 11 行批1 测试遗留(全 deleted=1)先物理清空再迁,保证 dev 库干净(ETL 脚本内做,幂等)。

### R6 与 v2 的语义差(有意保留,须在 02-实施 声明)

1. v2 认证失败=HTTP 401,v3=HTTP 200 + body code 401(芋道约定,批1 已定);
2. v2 删除靠 PG 外键冲突,v3 逻辑删除 + 显式引用检查(R3);
3. v2 竞赛"只切名单"PUT,v3 全字段 update;
4. v2 不存在返回 4004,v3 code 0 + data null(批1 已定);
5. v2 实验室详情/下载端点归批4(关联表未建)。
