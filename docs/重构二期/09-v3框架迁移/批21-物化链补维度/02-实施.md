# 批21 实施记录:物化链补 year/laboratory_id/granted_role(D-16 剩余项)

> 执行:2026-09-29|基线:`3be289d2`(批20)

## 为什么这是 Top1

核账代理判定 D-16 是唯一**随时间持续劣化**的数据正确性债:每审核通过一行,
物化出的 award 行 year/laboratory_id/granted_role 三列恒 NULL——实验室维度把
新行全归「未归属」,越晚修脏数据越多。数据源三列均已具备:
laboratory_id 随提交带上(PendingAchievementDO.laboratoryId)、year 可从 date
解析(v1 语义:date 是 YYYY-MM 或 YYYY-MM-DD)、granted_role 在抽取结果里。

## 交付

- `ReviewService.materializeAward` 补写三列;`parseYear` 从 date 取前四位,
  **解析不了返回 null 而不是猜**——统计按年分组,错年份比空年份难发现
- granted_role 取抽取结果,缺省「学生」(与批12 迁移 FILL 语义一致)
- ReviewFlowTest +2 用例:学生提交带 laboratory_id=5 → 物化行三列断言;
  granted_role=教师 照抽取值写 + date=2025-06 解析 2025

## 验证

ReviewFlowTest 11/11;后端全量 **142**(140+2)零失败。
