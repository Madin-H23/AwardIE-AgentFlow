## 四、本批修掉的 v2 缺陷

1. **伪 sha256 校验**:v2 的 preview 返回哈希、confirm 接收,controller 与 service 都不用;confirm 完全信任客户端 rows,可任意篡改。v3 改为服务端缓存 + 一次性 token(绑定主体),confirm 只收 token,篡改无效;
2. **导入无事务**:v2 `importRows()` 无 `@Transactional`,中途异常留半截数据。v3 整体一个事务;
3. **无行数上限/无表头校验**:v2 无上限、无行数限制。v3 上限 1000 行(超出明确拒绝)+ 严格表头文字比对;
4. **经费非法静默置 null**:v2 `tryDouble()` 失败变 null。v3 转行级错误,并校验非负与 `DECIMAL(12,2)` 上界(超界原本会让整批回滚);
5. **导入不建学生关联**:v2 导入只写项目表,学生端"我的大创"永远看不到新项目(28 行关联数据是一次性脚本灌的)。v3 导入时按学号自动建 leader + 尽力建 member;
6. **手拼成员 JSON**:v2 手工拼接字符串数组,成员名含引号/反斜杠就拼出坏 JSON。v3 用 Jackson,且按 V1 口径统一为对象数组 `[{姓名,学号}]`;
7. **只写年月按月首日**这类隐含语义,在解析器里显式注释固定,避免后续被"优化"掉;
8. **校准并发**:v2 `UPDATE ... WHERE id = ?` 无状态条件,两次并发会互相覆盖。v3 用 `AND status='进行中'` 做 compare-and-set。

## 七、跨批决策清账(2026-09-25 用户"全部按推荐")

### 决策1 软著登记号规则放宽(已落地)

- **事实取证**:V1 与 V2 库里的软著登记号**都是** `2024SR2002865`——4 位年份 + `SR` + 7 位流水号,13 位含字母。v2 的"20 开头 + 长度 11"规则会把它判非法,且 v2 自己的报错文案示例就是这个 13 位含字母的格式,**规则与示例自相矛盾**(批4 发现,批4-批8 一直挂账)。
- **落地**:改为正则 `^20\d{2}SR\d{7}$`,文案改为"4 位年份 + SR + 7 位流水号,如 2024SR2002865"。
- **测试**:回归锚点直接用 V1/V2 的真实数据 `2024SR2002865`;补 5 类非法值(年份错、流水号 6 位、纯 11 位数字、SR 小写、流水号含字母)。
- **连带修正**:`PendingSubmissionControllerTest` 的软著夹具原用旧格式 `2023SR12345`,已被新规则判非法导致 1 例失败,已改为真实格式。

### 决策2 project_no 改租户内唯一 + 逻辑删除不占位(已落地)

- **改造前**:`UNIQUE(project_no)` 全表唯一 → A 租户用了 `DC-001`,B 租户就不能用;且逻辑删除后编号仍被占,无法重建。
- **落地**:生成列 `active_project_no`(`IF(deleted=0, project_no, NULL)` 虚拟列)+ 复合唯一键 `(tenant_id, active_project_no)`。MySQL 唯一索引不约束 NULL,故"仅活动行参与唯一"。
- **实测三条语义全部通过**(非只看表结构):同租户同编号重复被拒(1062)、跨租户同编号可用、逻辑删除后可复用。
- **踩坑一处**:第一版只加生成列**没含 tenant_id**,实测"跨租户同编号"仍失败——唯一键必须含租户维度。已修。
- **脚本两条路径都通**:全新库由 `awardie-business.sql` 建表语句直给最终形态(无后续 ALTER,故重放不会撞 1091);旧库走一次性脚本 `scripts/migrate_project_no_tenant_unique.py`(带幂等守卫 + 重复数据前置检查,已实测二跑 skip)。应用层查询早已按 `(projectNo, tenantId)` 走,**Java 侧零改动**。

### 决策3 preview 缓存生产换 Redis(本批不改,转部署约束)

现状是单实例内存缓存(带主体绑定与容量上限)。**换 Redis 属架构变更**(序列化、测试基线、性能),当前无多实例需求,贸然引入会给批9 加无关复杂度。故本批不换,改为**部署约束**:"yudao-server 多实例部署前,必须把 `InnovationImportCache` 换成共享缓存,否则 confirm 可能打到另一实例报'预览已失效'"。已记入本节与遗留清单,批11 切流前复查。
