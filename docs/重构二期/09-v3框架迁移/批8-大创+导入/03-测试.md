## 二、测试纪律(沿用批7 立的三条)

1. **清理用物理 DELETE**:MyBatis-Plus 逻辑删除会留 `deleted=1` 行,后续"取第一条"会拿到历史行导致断言落空(批7 踩过三例)。`cleanBusinessTables()` 显式物理删,并在 `@BeforeEach` 与 `@AfterEach` 双清;
2. **只改用户→角色绑定**(`assignUserRole`),菜单归属由 SQL 负责,禁用 `assignRoleMenu`(全量替换语义会抹掉他人授权);
3. **本地复跑前先清 Redis 库 1**:批6 已知纪律——权限三级缓存键不含库标识,不清缓存会随机 403(本批复现了一次:`LaboratoriesControllerTest` 单跑失败、`FLUSHDB` 后通过)。CI 每次干净 Redis 不受影响。
