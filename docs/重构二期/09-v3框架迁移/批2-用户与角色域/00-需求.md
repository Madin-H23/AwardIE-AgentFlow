## 一、背景与目标

v3 已有芋道 stock 系统模块(用户/角色/菜单)和清理后的最小集(1 个 admin)。批2 把 **v2 的用户域**迁进来:1834 个存量用户(student 1793/teacher 40/admin 1)、三角色、werkzeug scrypt 口令、v2 特有的资料扩展字段。出口状态:v3 能用 v2 同一批账号口令登录,角色语义与 v2 对齐,为批 3-12 的业务域(提交/审核都挂在用户上)提供地基。

## 二、需求条目

### R1 口令迁移(决策 D1:scrypt 兼容+登录升级,**待用户复核**)

- v2 口令为 werkzeug scrypt 格式(`scrypt:32768:8:1$salt$hex`,1834 条同构);芋道原生 BCrypt;
- v1/v2/v3 各自独立数据库(ADR-0002),v3 升级哈希不跨系统打断——升级无外部约束;
- 落地:业务模块提供 @Primary PasswordEncoder(scrypt 前缀→BouncyCastle 校验;其余→BCrypt),登录成功即用 BCrypt 重编码并落库(登录升级,用户无感);
- 备选(未选):强制改密(1793 学生被迫改密)/永久 scrypt(永久偏离上游栈)。

### R2 角色体系(决策 D2:三角色全新建,**待用户复核**)

- 新建三角色:code=`awardie_admin`/`awardie_teacher`/`awardie_student`,v2 三角色一一对应;
- 保留芋道既有 super_admin/common 不动;业务权限点按角色授予(如 laboratory 四权限点给 admin);
- 备选(未选):admin 复用 super_admin/只用 common+权限点。

### R3 存量用户 ETL(决策 D3:全量+保留 v2 id,**待用户复核**)

- PG `awardie_dev.users` 1834 条 → MySQL `awardie_v3.system_users`(显式带 v2 id,自增序列拉到 max+1);
- 字段映射:login_code→username、name→nickname、phone→mobile、user_activated→status(true→0 正常/false→1 停用)、role→三角色之一、creator/updater='etl'、tenant_id=1;
- v2 admin(id=1)与 stock admin(id=1)同行覆盖:stock admin 被 v2 真实 admin 替换(口令随之变为 v2 的);
- 幂等:可重复执行(按 username ON DUPLICATE KEY UPDATE);执行后计数/v2 id 保真/哈希格式不变三项校验;
- 备选(未选):login_code 重映射+映射表/只迁 admin+teacher。

### R4 资料扩展字段(决策 D4:建扩展表本批一起迁,**待用户复核**)

- 芋道 system_users 装不下 v2 的 major/grade/title/qq/skills/profile_is_public;
- 新建 `awardie_user_profile`(user_id PK 外键、major、grade、title、qq、skills、profile_is_public),与 system_users 同批 ETL;
- 备选(未选):只迁核心字段,扩展字段留到门户批。

### R5 登录态语义对齐

- v2 登录字段 account=login_code;v3 芋道登录 username=login_code 同值——ETL 即对齐,无附加改造;
- 租户:单租户(id=1,芋道源码租户保持),登录头 tenant-id:1 不变。

## 三、范围边界

**In**:R1-R5。**Out**:部门/岗位树(v2 无,不建);OAuth2/社交登录;用户自助注册(芋道有,本批不配);学生/教师门户页面(批10);批12 成果数据外键迁移(本批只保 id 保真,外键迁移在批12)。

## 四、总验收

1. ETL 脚本可重复执行,1834 用户+1834 资料行落库,v2 id 一一对应;
2. 任取 v2 账号口令在 v3 登录成功(HTTP 契约),登录后该用户口令哈希变为 BCrypt(升级实证),二次登录仍成功;
3. 三角色落库且 admin/teacher/student 各取一样本验证角色关联;
4. 测试:scrypt 兼容+升级路径有集成测试;ETL 幂等+计数有验证记录;批1 既有 3 例不回归;
5. 三道闸+p3c 通过;CI 绿。
