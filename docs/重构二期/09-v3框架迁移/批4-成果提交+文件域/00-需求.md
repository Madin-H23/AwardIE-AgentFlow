## 三、需求条目

### R1 文件域等价物(决策 D1:自建,**用户已确认**)

- business 模块实现 `AwardieFileStorage`:目录存储 + SHA-256 去重 + 三校验(顺序沿 v1/v2:先扩展名 → 再大小 → 再魔术字节)+ 路径越界防护 + `readAll`/`contentTypeOf`;
- 存储根走配置 `awardie.file.root`(默认 `files/v3`),**测试注入 target/test-files**(避免污染与 CWD 分裂,沿 v2 批3 教训);
- 校验失败抛业务异常(带明确中文原因),不落盘任何不合规文件;
- 芋道 infra 文件模块**保留不动**(不删不改不迁移),本批不用它——理由:三校验与 sha256 去重是业务硬要求,走云客户端会丢这两条语义。

### R2 提交流(决策 D2:只做提交侧,**用户已确认**)

- `awardie_pending_achievements` 表按 F4 落列(批5/6 才用的列先留:reviewer/review/assigned_reviewer_type/ocr_text/llm_*/ext_info/session_id/version),JSONB 列在 MySQL 用 JSON 类型;
- 端点四件套:提交(POST multipart)、我的提交(GET 分页)、撤回(DELETE,仅本人且 pending)、文件下载(GET,attachment);**时间线与审核动作不在本批**;
- 五类成果字段校验按 F12 与 v2 逐条对齐,校验结果落 `validation_result` JSON(is_valid/content_issues/completeness_issues);
- **sha256 去重**:同 hash 且 status=pending 拒(4001);教师也可提交且 submitter_type 按实际角色;
- 状态机初值 status=pending、version=1;驳回后重新提交是新行(v2 语义,本批不实现驳回)。

### R3 实验室关联域(决策 D3:一并做,**用户已确认**)

- 建四表:`awardie_laboratory_downloads` / `awardie_laboratory_images` / `awardie_laboratory_instructors` / `awardie_laboratory_students`(对照 F9 的 v2 结构);
- 实验室详情聚合端点 + 下载列表端点(v2 `labDetail`/`labDownloads` 等价物);**awardCount 依赖 awards 表(批6),本批该字段返回 0 或省略**——按"不静默降级"原则,字段保留但注释标明批6 补;
- **引用清单衔接**:四表追加进批3 的 `AchievementReferenceChecker.LABORATORY_REFERENCES`,删实验室被引用即拒(批3 遗留项,见 02-实施 遗留节)。

### R4 权限与菜单

- 新增权限点:`business:pending:*`(create/query/delete)与 `business:laboratory:*` 详情/下载(复用批3 的 query 权限);菜单固定 ID 幂等,授予 awardie_admin(100)与 super_admin(1);
- 学生门户的"我的提交"走 `business:pending:query` + 数据隔离(只看自己的),不按角色硬分——芋道权限点 + service 层 submitter 过滤双保险。

### R5 数据迁移(决策 D4:不迁,**用户已确认**)

- 本批只交代码与表结构;588 条 pending + 30MB 文件实体留给批12;dev 库验收用测试自造数据。

## 四、范围边界

**In**:R1-R5。**Out**:审核动作与时间线(批5);awards/patents/... 五表物化(批6);模板与 AI 抽取(批7);xlsx 导入(批8);前端页面(批10);小程序(批11);存量数据与文件实体迁移(批12);审计日志表(achievement_audit_log,随批5 审核流一起建,本批提交侧只做 pending 表)。

## 五、总验收

1. 文件域:三校验各有一条拒绝实证(非 jpg/pdf 扩展名 / 超 10MB / 魔术字节不符),合法文件落盘+sha256 去重+resolve 越界拒绝;
2. 提交流:五类成果各能提交并落 pending 行(字段校验结果正确);重名 hash+pending 拒;教师提交 submitter_type=teacher;撤回仅本人且仅 pending;下载 attachment 且非本人非教师/管理员 403;
3. 实验室关联:详情聚合与下载列表端点可用;四表进引用清单后删实验室被拒;
4. 测试:新增集成测试全绿、全量 `mvn -B test` 0 失败;p3c 增量 0;三道闸 0 High/Critical;CI 绿;swagger 截图 + dev 端到端实证。
