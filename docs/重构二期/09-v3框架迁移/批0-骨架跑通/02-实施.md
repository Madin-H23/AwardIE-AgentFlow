## 偏差与发现

1. **默认管理员口令是 `admin123` 而非文档流传的 `a123456`**——种子 hash(bcrypt $2a$04$)实测匹配 admin123;上游文档滞后,已实测纠偏;
2. **tporadowski redis 最新 release 是 v5.0.14.1**——网上教程普遍写 v2.8.2101(已 404,镜像返回 9 字节错误页),查 api.github.com/releases/latest 才拿到正确资产名;
3. 登录无需验证码(该版本默认配置),tenant-id 头传 1;
4. 默认装配仅 system+infra 两模块(bpm/ai/mp/pay/mall 等全注释),RabbitMQ 配置块存在但 server pom 无 MQ starter,启动不依赖。
