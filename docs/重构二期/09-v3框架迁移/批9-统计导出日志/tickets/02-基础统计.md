# 02 — 基础统计(计数 + 五类分类 + 竞赛 Top)

**What to build:** `GET /business/stats/overview` 返回 `summary`(awardsTotal/pendingSubmit/usersTotal/competitionsTotal/whitelist)+ `category`(award/patent/software/innovation/other 五类);`GET /business/stats/by-competition` 返回竞赛 Top12。全部 SQL 显式 `deleted = b'0' AND tenant_id = ?`(JdbcTemplate 不经租户拦截器,批8 已实证同款问题)。计数用 `Long` 而非 v2 的 `Integer`(大表溢出)。竞赛 Top 用 `LEFT JOIN competitions` + `COALESCE(competition_name,'未关联')` 保留无主成果,并**加 `name ASC` 二级排序**(v2 只有 `ORDER BY total DESC`,同数时行序随机,截图/对账会漂)。菜单 3007 + 权限点 `business:stats:query`。**不做**年份趋势(靠 awards.year,物化不写)、实验室维度(同)、教师证书拆分(awards 表无 granted_role 列)——三者已记为前置债。
