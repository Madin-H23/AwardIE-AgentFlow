# 03 — 数据导出(竞赛年度汇总 + 学生获奖明细,CSV/XLSX)

**What to build:** 两类导出各支持 `.csv` 与 `.xlsx`:
- `GET /business/export/competition-summary(.csv|.xlsx)`:竞赛 × 年份 × 获奖等级汇总(走 `awardie_awards` join `awardie_competitions`,竞赛关联在 v3 完整);
- `GET /business/export/student-affairs(.csv|.xlsx)`:学生获奖明细(走 `awardie_award_student_winners` join `system_users`)。

修 v2 三处缺陷:①"学号"列取 `system_users.username`(v3 的 username 就是学号,批2 ETL 事实),**不是** users.id(v2 选错导致导出的是内部数字 ID);②CSV **防公式注入**(以 `=`/`+`/`-`/`@` 开头前置单引号转义,v2 只做 RFC 引号转义会被 Excel 当公式执行);③**行数上限**默认 10000 可配,超出报错不静默截断(v2 只有年度明细 500、其余无上限)。走显式 DTO 不用 `row.values()` 顺序假设(v2 依赖 JDBC Map 迭代序对应 SELECT 列序,换驱动/别名就错列)。CSV 保留 UTF-8 BOM(Excel 中文不乱码)。XLSX 用已有 FastExcel starter 单 sheet + `@ApiAccessLog(EXPORT)`。菜单 3008 + 权限点 `business:export:query`。
