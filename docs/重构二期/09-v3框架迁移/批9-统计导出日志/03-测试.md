## 二、与 v2 测试水平的本质差异

v2 的 `AdminStatsTest` **只验响应结构不验聚合数值**(取证确认:无固定数据夹具)。那种测试无法发现 SQL 口径错误——v2 的统计 SQL 就藏着 `GROUP BY c.id` 依赖 PG 主键函数依赖(MySQL `ONLY_FULL_GROUP_BY` 下直接报错)这类问题。

本批全部统计断言用**固定数据夹具锁死确切数值**,并因此在开发期就抓出了真实的 SQL 拼接缺陷(见 `02-实施` 第三节)。

## 三、测试纪律(沿批7/批8)

1. **清理用物理 DELETE**:MyBatis-Plus 逻辑删除会留 `deleted=1` 行,后续"取第一条"会拿到历史行导致断言落空(批7 踩过三例);
2. **只改用户→角色绑定**(`assignUserRole`),禁用 `assignRoleMenu`(全量替换语义会抹掉他人授权);
3. **本地复跑前先 `redis-cli -n 1 FLUSHDB`**:批6 立的权限三级缓存纪律——`system_user_role` 直插不驱逐缓存,不清缓存会随机 403。
