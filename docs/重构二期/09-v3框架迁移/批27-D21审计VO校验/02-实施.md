## AuditActionType 接口→枚举(本批的结构性改动)

`@InEnum` 校验器只吃**实现了 ArrayValuable 且至少一个常量的枚举**
(`getEnumConstants()[0].array()`,零常量枚举会全拒)。原 `AuditActionType` 是
常量接口 → 转为枚举 `implements ArrayValuable<Integer>`:
- 爆炸半径实证=生产仅 `AuditLogService.label()` 一处 + 同包单测一处,零破坏转换
- `label()`/`LABELS` 行为不变(单测原样通过);新增 `ARRAYS` 供校验器取值
- **转换踩的两脚**:①接口成员隐式 public,枚举里裸写变包私有 → 跨包编译炸(补 public);
  ②`LABELS` 忘写 static,实例初始化期自引用常量 → 类初始化必炸(补 static final)
