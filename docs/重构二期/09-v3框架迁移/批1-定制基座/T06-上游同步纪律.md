## 三、升级 SOP(上游拉新基线)

1. **拉新基线**:在 `AwardIE-v3` 镜像 clone(或重新 clone) checkout 上游最新 `master-jdk17`,记录新 commit;
2. **导出**:`git archive HEAD | tar -x -C <staging>`,与库内 `awardie-v3/` 逐文件比对,生成差异清单;
3. **脱敏**:`python scripts/v3_sanitize_sql_secrets.py`(cloud-key 演示串→`DEMO-REMOVED-BY-AWARDIE`;CI 有 --check 守卫,**任何 SQL 变动必须先跑**);
4. **清理**:官方 sql 导入后重跑 `awardie-v3/sql/awardie-cleanup.sql`(幂等);
5. **应用四类改动**:A 类坐标重新替换(脚本化,勿手改);D 类口令占位符;保留 B/C 类我们的文件不动;
6. **三方冲突优先级**:业务模块 > 清理脚本 > 坐标替换 > 上游文件(冲突时优先保我们的,上游侧记录到升级日志);
7. **验证链**:`mvn -B test`(需 PG? 不——MySQL 3307+Redis+测试库五脚本)→ 全量绿 → 提交 `chore(v3-upstream):` → CI;
8. **排除项复查**:上游若修复 `CodegenEngineUniappTest`(WOT 树表模板映射),删除根 pom 中的排除块。
