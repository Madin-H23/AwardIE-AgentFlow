## 三、GUI 测试抓出的两个缺陷(已修)

详见 [04-gui测试报告](04-gui测试报告.md)。这里只记根因,它们比「功能 missing」更有价值:

### 缺陷 1(高):`submitPending` 的 multipart 形态错误 —— 批10 潜伏,双角色同症状

yudao 的 axios 封装 `request()` 无条件 `Content-Type: headersType || default_headers`,
`request.post` 即 JSON 头;FormData 被当 JSON 序列化,后端
`MultipartException: not a multipart request` → 500。正确写法是 `request.upload`
(自带 `headersType: 'multipart/form-data'`,全仓库唯一先例是 infra 文件上传)。

**影响面是双角色的**:学生门户的提交自批10 起同样会 500——此前从没被发现,
因为提交链路只有 MockMvc 级测试(MockMvc 直接调后端,测不到前端请求形态)。
这正是用户要求「用 GUI 技能测一遍」的价值:黑盒端到端第一枪就命中了三层门禁
(单测/集成/CI)都照不亮的盲区。

**修复**:`submitPending` 改走 `request.upload`。学生/教师共用同一函数,一并修复。

### 缺陷 2(低):教师页提交时间显示裸时间戳

el-table 直接绑 `createTime`(epoch ms)→ `1790597603000` 直出。
修:挂项目标准 `:formatter="dateFormatter"`,字段改为语义正确的 `submitTime`。
