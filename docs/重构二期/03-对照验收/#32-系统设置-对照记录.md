# #32 系统设置 对照记录

> v1 源:`app/templates/admin/settings.html`(810 行)+ `backend/models/auto_archive_config.py` + `app/utils/_core.py::get_default_password`。

## 一、v1 区块清单(实现前提取)

三 tab:
1. **通用设置**:系统默认密码(config/settings.json 的 system.default_password,页面可改)+缓存清理按钮(OCR/抽取缓存)。
2. **供应商设置**:OCR 默认供应商+API Key;LLM 默认供应商+API Key(页面表单,写 config)。
3. **自动归档**:奖状/专利/软著(valid/invalid 两态)与大创/其他(单态)的自动归档开关矩阵;仅对学生提交生效;写 `auto_archive_config` 表(achievement_type × validation_status → enabled)。

## 二、v2 落法与架构偏差声明

- **自动归档 = 真读写**:`auto_archive_config` 表已在 v2 baseline(同构);`GET/PUT /api/v2/admin/settings/auto-archive`,五类型开关矩阵(award/patent/software 各 valid/invalid 两行,innovation/other 单行),el-switch 批量保存。
- **通用设置/供应商设置 = 只读信息卡(架构偏差)**:v1 从 config/settings.json 与 config 文件读写默认密码/OCR·LLM 供应商密钥;v2 架构下这些属**外部化配置**(application.yml/环境变量),由部署管理而非页面修改——页面渲染只读说明卡(当前 ai.worker.mode、默认密码管理方式),不渲染假开关。缓存清理:v2 无对应缓存表,不渲染。
- 三 tab 结构 1:1(el-tabs);写操作走 CSRF(apiJson)。
