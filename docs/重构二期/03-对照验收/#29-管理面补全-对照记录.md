# #29 管理面补全+排版统一 对照记录

> 用户实测反馈(2026-08-31):①侧边栏只有 4 项,v1 不止;②各页排版不一致、数据展示不美观。
> 本票=排版基因统一 + 五个数据基础最好的页面(日志/学生/教师/实验室/模板)补全 + 侧边栏全量对照 v1。

## 一、问题根因

1. **侧边栏缺失**:#25 时"v1 独有页不渲染防死链"的决策过于保守——用户要的是功能完整,不是菜单隐藏。
2. **排版不协调**:v2 各页由不同 ticket 时期独立编写,自创 max-width(720/1000/1100/1200)与容器风格各异;v1 是全宽+统一视觉基因(console_tokens.css"页面视觉基因"段),v2 从未移植。

## 二、本轮落地

### 排版统一(治本)
- tokens.css 新增"页面视觉基因"段(移植 v1 L281-327):h1/h2/h3 字阶、`.c-panel` 统一面板、page-head 两端对齐、page-alert 全局化、el-table 灰表头基因(--el-table-* 变量桥接)、el-card 对齐 c-panel(去阴影)。
- **废除全部自创 max-width**(8 处:Home 720/Dashboard 1200/Awards 1200/Competitions 1000/Review 1100/Profile 640/Submit 1100),统一 v1 全宽;ComingSoon 居中卡片保留。
