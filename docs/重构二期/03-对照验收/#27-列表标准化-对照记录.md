# #27 列表标准化 对照记录

> 基调:对照 v1 成果管理页的筛选表单形态(`awardFilterForm` inline 表单区在表格上方,字段回填 URL 参数),以 Element Plus 实现统一标准化。
> 依赖 #25(shell)/#26(真分页四维筛选)已落地。

## 一、v1 形态(实现前提取)

- 筛选区:表格上方 inline 表单(输入框+下拉),查询后参数回填 URL(`page/per_page/is_abnormal` 等),翻页保留筛选。
- 列表:服务端分页,total_count+total_pages。

## 二、v2 落法

1. **`src/composables/useTablePage.ts`**:分页(1 基展示/0 基请求)+筛选(空值剔除)+loading 统一态;`search()` 回第 1 页、`reset()` 还原初始筛选;响应默认解 Page/PageView(content/totalElements),可自定义 extract。
2. **AdminAwardsView**:筛选表单区四维=关键词(el-input,jsonb 模糊)+类型/状态(el-select)+提交于(el-date-picker daterange → dateFrom/dateTo);查询/重置按钮;`v-loading` 接表格;翻页保留筛选。
3. **AdminCompetitionsView**:接入 useTablePage(q 竞赛名模糊,enter/clear 触发)+loading+分页条。
4. **TeacherReviewView**:仅补 `v-loading` 统一态——待审列表数据量小且后端端点无分页参数(#9 语义:待审即单一 pending 状态),不加筛选区与分页,防伪需求。

## 三、验收

vite build 过、eslint 0 error、裸控件门禁过、pages E2E 8 条过(admin 成果管理/竞赛管理断言不回归)。
