# #31 数据导出 对照记录

> v1 源:`app/templates/admin/data_export/main.html`(58 行,三 tab 骨架)+ `app/routes/admin_export.py`(department_summary_export 生成 openpyxl xlsx 报告+图片 zip)。

## 一、v1 区块清单(实现前提取)

- 页面头「数据导出」;三 tab:**系年度总结**(参数:起止日期+年份+是否含图片;导出 xlsx 多 sheet 报告+图片 zip)/ **学生事务** / **教师个人**(按人导出)。
- 导出端点:POST json {start_date,end_date,year,include_images,teacher_id} → xlsx/zip 附件。

## 二、v2 落法与偏差声明

- **格式偏差:CSV 起步**(票面允许项)。v1 的 openpyxl 模板化报告(多 sheet 样式+图片 zip 打包)为重实现,不移植;v2 以 UTF-8 BOM CSV 提供同数据面,Excel 可直开。xlsx 模板报告挂账。
- 三 tab 结构 1:1 复刻:
  - 系年度总结:年份+起止日期参数 → `GET /api/v2/admin/export/department-summary.csv`(按竞赛×月度聚合的获奖汇总);
  - 学生事务:`GET /api/v2/admin/export/student-affairs.csv`(学生×获奖明细:学号/姓名/竞赛/等级/年份);
  - 教师个人:`GET /api/v2/admin/export/teacher-personal.csv`(教师×指导/获奖明细)。
- Content-Disposition attachment+文件名含时间戳;CSRF 对 GET 无要求。
- 看板页导出按钮(此前 disabled)接真实链接,指向系年度总结 CSV(当前年份全量)。
