# #30 数据分析 对照记录

> v1 源:`app/templates/admin/data_analysis.html`(249 行)+ `app/static/js/data-analysis.js` + `backend/managers/data_analysis_manager.py`。

## 一、v1 区块清单(实现前提取)

- 页面头「数据分析与导出」;三 tab:竞赛信息 / 竞赛分析 / 获奖数据分析。
- **Tab1 竞赛信息**:timelineChart(ECharts 400px,时间点标记散点图:报名开始/比赛时间/出奖时间)+竞赛表格(竞赛名称/时间范围/官网/白名单,含获奖数)。
- **Tab2 竞赛分析**:筛选 c-panel(年份多选标签 year-tags+「仅白名单赛事」+「包含教师证书」checkbox,默认只看学生奖状)+竞赛贡献度图(500px,按奖状数排序)+竞赛×实验室获奖热力图(min 650px)。
- **Tab3 获奖数据分析**:左 1/4 图表设置(X 轴=年份|实验室;颜色分组=实验室|年份|竞赛等级;图表类型=分组柱状|折线|甜甜圈;更新按钮)+右 3/4 动态图(960px)。

## 二、v2 落法与偏差声明

- 后端 `AnalysisController` 四只读端点:`/admin/analysis/competitions`(竞赛+award_count+时间原串)、`/contribution`(years/whiteListOnly/includeTeacher,GROUP BY 竞赛)、`/heatmap`(竞赛×实验室 COUNT)、`/records`(明细行:year/lab/competition/level/granted_role,供 Tab3 前端聚合)。
- **偏差:Tab1 时间线图降维**——v1 三时间点散点依赖 python `parse_competition_time` 对 `competition_time` 方言串('10-4月' 等)的解析;迁移库该列为杂格式 TEXT,v2 不移植解析器,时间线改为竞赛获奖体量横向条形图,时间范围以原串呈现在表格列。信息价值保留,解析器移植挂账。
- Tab3 动态图聚合在前端完成(records 明细 ≤ 数千行),后端不按 X 轴/分组组合建端点。
- 前端三 tab 用 el-tabs;年份多选标签用 el-check-tag(对照 v1 year-tag 视觉);图表 ECharts,随暗色主题重绘。
