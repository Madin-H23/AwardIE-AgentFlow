- catch-all 必须置于路由表**末尾**(vue-router 按序匹配,置前会吞掉所有路由)。
- `<script setup>` 内直接 import 图标(与 ComingSoonView 惯例一致),不混用第二 script 块。
- min-height 60vh + flex 居中,无壳页面自身撑起视觉,不依赖任何 layout。
