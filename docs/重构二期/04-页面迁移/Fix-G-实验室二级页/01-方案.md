# Fix-G 实验室二级页迁移方案(详情/编辑/下载专区)

> 批次:Fix-G|范围:laboratories/detail.html(876 行)、edit.html(1047 行)、downloads.html(118 行)
> 基调:对照 v1 结构与设计 1:1,仅换 Element Plus;文档三段式(方案→实施→测试)。

## 一、v1 结构提取(编码前)

### 1. detail.html(876 行)区块
1. **实验室头部大图**:封面图(laboratory_images 首图/cover_image)+ 渐变遮罩 + h1 名称
2. **成果统计横条**:competition_count 等统计值(laboratory_images/下载计数等来源)
3. **团队信息两列**:指导教师(laboratory_instructors JOIN users)/学生成员(laboratory_students JOIN users),空态"暂无"
4. **成果展示区**(achievements-section):实验室关联成果卡片
5. **实验室图片区**(lab-images-section):图片墙
6. **下载专区入口**:文件列表(laboratory_downloads)

### 2. edit.html(1047 行)表单字段
仅三字段:**name(必填)/ description / cover_image(图片上传)**。编辑页体量主要在图片上传交互,核心字段极简。

### 3. downloads.html(118 行)结构
页头(实验室名 - 下载专区)+ 面包屑 + 文件列表表(文件名/大小/时间)+ 计数徽标。

## 二、v2 设计

### 后端新增(挂 AdminConsoleController 或独立 LabPortalController)
| 端点 | 语义 |
|---|---|
| GET /admin/laboratories/{id}/detail | 实验室信息+统计+团队(教师/学生名单)+下载文件列表 一次聚合 |
| PUT /admin/laboratories/{id} | 编辑三字段(已有 update 扩 name/description;补 cover 占位) |
| GET /admin/laboratories/{id}/downloads | 下载文件列表(file_path 存在才可下载,BR-7 attachment) |

### 前端新增(挂 portal 语义的 admin 壳内)
| 页面 | 路由 | 对照 |
|---|---|---|
| LabDetailView | /admin/laboratories/{id} | 头部卡(封面/名称/简介)+统计+团队两列+下载列表 |
| LabEditView | /admin/laboratories/{id}/edit | 三字段表单(封面上传挂账) |

### 偏差声明
1. 封面图上传:依赖文件存储,先保留现有 cover_image 字段展示(有则显示图,无则渐变占位),上传交互挂账;
2. detail 的"实验室成果展示卡片"依赖 laboratory-awards 关联查询,本轮以计数统计呈现,完整成果列表挂账(数据链路:laboratory_id 直查 awards 可行,下批补);
3. downloads 上传入口不搬(仅展示+下载,上传属文件导入通道)。

## 三、验收标准
- 三页对照 v1 区块 1:1(除声明偏差);detail/edit/downloads 各一截图留档
- 后端聚合端点测试(详情聚合/下载列表/404);E2E:卡片点击进详情、编辑回显、下载触发
