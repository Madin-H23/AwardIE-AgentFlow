## 二、laboratory_data_analysis 迁移方案

### v1 契约(实读)
- 路由 `/laboratories/{lab_id}/data-analysis`(admin+teacher 同模板),两 tab + 年份多选:
  - tab1 竞赛贡献度:`GET /api/admin/laboratory/{labId}/data-analysis/competitions`(该实验室在各竞赛的获奖计数,条形图)
  - tab2 竞赛×实验室热力图:`GET /api/admin/data-analysis/lab-competition-heatmap?years=`(**全局**热力图,非 per-lab)

### v2 落点
- 后端 AdminAnalysisController 增 `GET /analysis/laboratory/{labId}/contribution?years=`(WHERE a.laboratory_id=?,键名与全局 contribution 一致:competitionId/name/awardCount);热力图**直接复用既有 /heatmap**
- 前端 LabDataAnalysisView(`/admin/laboratories/:id/analysis`):两 tab(echarts 条形图+热力图,组件模式照抄 AdminDataAnalysisView)+ 年份 el-check-tag 多选;LabDetailView 页头加"数据分析"按钮入口
- 404:实验室不存在→4004;权限 requireAdmin(v1 require_login 含教师,v2 收敛 admin 与 R/T 批口径一致,偏差声明)
