## 冒烟过程中修的两个真错

1. **模板管理器取法**:`ToolContext` 无 `template_manager` 属性(codegraph 注释误导);`backend/extract/template/manager.get_template_manager` 亦不存在(award.py:805 的 import 在 try/except 内,从未生效=潜在死代码)。终取 `get_context().template_manager`(ServiceContext 公开 property,与 extract_framework 同源单例)。
2. **Java 测试 cookie/token 同源**:adminCk() 每次调用都是独立登录,cookie 与 xsrfFrom 必须取自同一次登录,否则 CSRF 403。
