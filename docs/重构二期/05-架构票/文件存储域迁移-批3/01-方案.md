## 五件套

1. **存储根参数化**:`FileStorageService` 构造器注入 `files.root`(默认 `files/v2`,生产零改动);BaseIntegrationTest 注入 `files.root=target/test-files`——测试文件落 target(随 mvn clean 清理),**根除"测试 JVM 写 awardie-backend/files、运行后端读写项目根 files"的两处 CWD 分裂**(批 2 两次 cp -n 合并的根治);
2. **下载语义单一真源**:提交文件下载(`GET /api/v2/files/{id}/download`,BR-7 attachment+权限门)改走 `storage.readAll`(resolve 白名单内聚);inline 展示端点(模板图/证书图)已在批 1/2 收敛——全站文件读路径只剩 FileStorageService 一条;
3. **V5 迁移**:`templates` DROP `sample_image_blob`(前置=批 1 脚本已在 awardie_dev 20/20 搬运置空;测试库/CI 无 blob 数据);
4. **存量 v1 文件 ETL**(`scripts/etl_v1_files_to_v2.py`):扫描 `files/{agent_upload,other,awards,patents,software,laboratories}`(38 个文件)→ sha256 内容寻址落 files/v2(魔数判型;同内容去重)→ 全量回读校验 → 按哈希重连 `other_files.file_path` / `awards.certificate_path`(仅填空;**仅当 DB.file_hash==内容 sha256 才连**,防 v1 哈希算法不一致的脏连);幂等可重放;
5. **验收**:抽样 md5 即全量回读哈希比对(38 量级不做抽样);两下载/两展示端点语义一致(attachment vs inline)。
