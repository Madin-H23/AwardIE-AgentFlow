## 本批踩坑

- **脚本 ROOT 少一层 `.parent`**:`scripts/x.py` 的 `resolve().parent` 是 scripts 目录——ETL 首跑"找到 0 个文件";独立最小复现(同 cwd 同解析式)定位后补 `.parent`;
- 下载探针两连错( achievements 列表参数猜错/路由前缀少 `/student` 段)——**探针端点路径必须从 Controller `@RequestMapping` 源码取证,不靠猜**。
