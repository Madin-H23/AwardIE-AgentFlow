## 二、目标(架构决策)

1. **统一存储方案**(票核心决策点):建议收敛为**目录存储(FileStorageService 扩展为通用文件域服务)**,理由:大文件 DB 膨胀风险(样本图 598KB/张×模板数+证书图)、下载流式化天然支持、与 v1 files/ 目录形态对齐利于存量迁移;BYTEA(templates)迁移为文件引用,`sample_image_blob` 保留过渡期兼容读或一次性数据迁移。
2. **awards 证书图片补链**:awards 增 file 引用列(Flyway migration),物化链(ReviewService.materialize*)携带 pending.file_path → awards;awards/edit 页图片从"hash 占位"升级为真图显示(Fix-R 挂账清偿)。
3. **上传端点补齐**:admin 域证书图片/封面上传端点(multipart,复用 FileStorageService 三校验)。
4. **下载端点统一**:既有零散下载端点(学生提交/lab downloads/模板图片)收敛到统一文件域路由(attachment 语义单一真源)。
5. **存量数据迁移**:v1 files/ 目录与 SQLite blob → files/v2/ 布局(pgloader 外的文件 ETL,一次性脚本)。
