# 文件存储域迁移 批2:awards 证书链(三段文档 01)

> 归属:《文件存储域统一迁移》架构票交付物 2(D3a 拍板:awards 补证书文件引用,清偿 Fix-R"hash 占位"与 Fix-T"证书文件"两挂账)。

## 四件套

1. **V3 迁移**:`awards` 加 `certificate_path VARCHAR(500)` + 存量回填(pending_achievements.archived 行按 `file_hash = image_hash` 接回 `file_path`);
2. **物化链携带**:`ReviewService.materializeAward` INSERT 增加 `certificate_path = e.getFilePath()`——批准入库即带图,新断链不再产生;
3. **admin 两端点**(AdminAwardEditController):`GET /{id}/certificate`(inline 回显)+ `POST /{id}/certificate`(三校验+store,上传/替换);edit-detail 聚合补 `certificatePath`;
4. **edit 页真图**(AwardEditView):certificatePath 有值→`<img>` 真图;仅 hash→提示"可上传补齐"(V4 清理后的历史数据态);上传按钮走新端点。

## 数据修正(V4,批内发现批内修)

V3 回填实测扫入 **22 条 v1 时代 `temp_upload/*` 路径**:不在 files/v2 白名单内且文件本体已失存(`files/temp_upload/` 目录空)。处置:V4 迁移将越界引用置空,回退到"仅有哈希,可上传补齐"的诚实状态;批 3 ETL 若找回文件按哈希重连。回填 101 条 → 清理后 **79 条有效引用**。

## 端点韧性(批 1 Low 转正)

`certificate()`/`image()` 对**磁盘文件缺失或越界路径**捕 NoSuchFileException/IllegalArgumentException → 404(替代全局 5000);`test()` 同场景 → 4004。

## 测试计划

JUnit 全量(含 ReviewLoopTest 新增证书链用例:提交→批准→断言 awards.certificate_path→回显 200→无图 404);端到端探针(上传真实 598KB 图→200/0→回读 200 image/png 598280);edit 页 MCP 实景截图;E2E 全量回归。
