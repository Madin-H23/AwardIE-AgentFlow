## 本批踩坑(四连,全与"字节/路径/编码"有关)

1. **psycopg2 BYTEA 返回 memoryview**:切片与 bytes 恒不等,魔数判型全落空——取回即 `bytes(blob)` 强转;
2. **初版脚本把绝对路径写进 sample_image_path**:FileStorageService.resolve 白名单要求相对路径(`files/v2` 前缀),图端点 400"非法路径"——脚本改存相对路径+oneoff 归正 20 行。**跨服务共享的路径值必须以消费方的校验口径为准**;
3. **UTF-8 字符串当字节流**:`"\u00FF\u00D8".getBytes(UTF_8)` 编成 `C3 BF C3 BF`,魔数从未进过字节流(老代码不校验所以从没暴露)——夹具改 `new byte[]{(byte)0xFF,...}` 字面量;
4. **测试遗留数据混入断言**:FixTP 夹具走"已有则复用"分支,复用到旧代码建的 path 为空的行→404——改为每轮清重建;顺带暴露 create 端点"先 INSERT 后验文件"会留孤儿行,校验已前置。
