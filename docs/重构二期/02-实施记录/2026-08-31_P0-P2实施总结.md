## 三、关键技术决策(答辩叙事点)

1. **作品导向范围收缩(ADR-0001)**:从"265 端点全量复刻"收缩为"纵切面+高频队列",长尾留 v1 并存——答辩考核心链路质量而非端点数。
2. **双库并存+按路径分流(ADR-0002)**:放弃原"单库影子读"方案(v1 有 18 处裸 sqlite3,改库即动生产),v1 零改动,Nginx 按域分流+窗口制切换——业务零中断的绞杀式迁移。
3. **口令哈希格式恒守**:发现"透明重哈希为 BCrypt"会断掉 v1 登录(werkzeug 无法验裸 bcrypt),修正为 Java 侧实现 werkzeug scrypt 兼容验密、改密产同格式——新旧系统双登录兼容。
4. **迁移语义考古**:v1 表约束是真实业务规则的"地层"(如 innovation_projects 限 admin 导入通道),迁移管线逐层核实,不臆测。
5. **探针先行**:gRPC 过 Nginx 断流(60s read_timeout)、SQLite→PG 六类坑位,均以 throwaway 探针先量化再进 spec。
