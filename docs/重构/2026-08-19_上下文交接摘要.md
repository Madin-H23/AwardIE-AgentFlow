## 5. 关键决策与教训（防新窗口重踩）

1. **Alembic 禁用 autogenerate**——会把未建模 20+ 表视为 DROP（已删灾难脚本，versions/ 禁用已测试固化）。迁移全部手写
2. **批量改码必须逐文件 diff 全量核对**（L3 事故教训：当时只修表面，残留到 ruff 硬门禁才暴露）
3. **SQLite UPDATE rowcount=-1 不可依赖**（子查询语义），验证须 LEFT JOIN 计数
4. **SQLite 生成列查 table_xinfo**（hidden 在索引 6），非 table_info
5. **Windows 路径 sqlite URL 须正斜杠**；临时测试库须完整 DDL（列不全 ORM SELECT 误判）
6. **测试环境自持原则**：dotenv 注入 FLASK_ENV 污染收集期——测试不依赖宿主环境变量
7. **monkeypatch 命名空间**：`from X import Y` 后须 patch 消费方命名空间
8. **优先零 mock 等价测法**（三次测试返工换来的纪律）
9. 前端 JS 改前必核实辅助函数存在；DB 变更后必须起真实 app 冒烟（版本列炸毁 dataclass 教训）
