# 门户深色与风格排障清单（复用检查项）

> 版本：v1.1 ｜ 日期：2026-08-20 ｜ 用途：把近期门户/审核页排查出的问题固化为**可复用检查表**——新增或复核页面时逐条核对，避免同型问题复发。
> 适用范围：`user_base.html`（Tailwind 门户体系）所有继承页（student/teacher/审核 portal 壳）与 `results_console/portal` 双壳。

| # | 现象 | 根因 | 修复模式（落地处） |

## 2. 复用检查项（新页/复核逐条核对）

- [ ] **字体**：页面是否保证 Noto Sans SC（尤其引入新 UI 库后）？`body{font-family:'Noto Sans SC'...}` 是否被后定义规则覆盖？
- [ ] **tokens 上下文**：使用 `var(--panel)/--brand/color-mix` 的组件，所在容器是否有 `.console-shell` 或 `.portal-shell`？tokens.css 是否已引入？
- [ ] **居中留白**：门户系页面内容是否在 `max-w-7xl mx-auto` 容器内（无全宽铺开）？
- [ ] **深色成对**：所有 `bg-white/bg-gray-*/text-gray-*/border-*` 是否成对（dark 类 或 依赖 user_base `!important` 覆盖）？改动 Tailwind 类后是否 `npm run build:css`？
- [ ] **僵尸链接**：有无 `href="#"` 未接线占位？
- [ ] **身份选壳**：师生操作页是否走 portal 壳、管理员走 console 壳（`_results_template`）？
- [ ] **硬编码色**：`grep -r "#[0-9a-fA-F]{6}"` 是否有漏网（白名单除外）？
- [ ] **标题层级**：页面 h1 是否统一门户风（1.5rem/700）而非浏览器/Bootstrap 默认？
