## 目录结构

| 目录 | 内容 |
| --- | --- |
| `重构/` | ⭐ 重构权威体系：需求(SRS)/设计(SDD)/实施记录/风险登记册/TODO 索引/交接摘要 |
| `架构解读/` | 逐蓝图源码解读系列（01 应用工厂 → 各业务蓝图，编号有序） |
| `测试方案/` | 手工回归清单 + 自动化测试要求（自动化执行以根目录 pytest 为准） |
| `用户指南/` | 面向使用者的功能说明（部分为历史版本，注意文中标注） |
| `运维指南/` | 启动、日志、路径、OCR 密钥等运维排查资料 |
| `归档/` | 历史资料集中地（不入 git；头部均有"已归档"标注） |
| `AI编程记录/` `TODO/` `modifications/` `问题分析/` | 内部开发过程记录（gitignore 排除，不对外） |
