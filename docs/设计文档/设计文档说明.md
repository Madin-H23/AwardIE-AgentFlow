# 核心模块

## 信息抽取模块

  输入任意文件，将文件分类，对于特定能够细致识别的种类（奖状，专利，软著，大创，其他），会有针对性地抽取有效信息，并且返回抽取内容。最重要最核心的就是奖状内容的抽取。

这个模块比较复杂，且支持扩展（通过注册更多的抽取器来扩展功能）。由下面几个部分构成：

