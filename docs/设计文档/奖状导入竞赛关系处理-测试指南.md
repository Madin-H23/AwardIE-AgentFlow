    def test_2_upload_file_and_check_warning(self):

## 7. 常见问题排查

### 7.1 警告提示不显示

**可能原因**：
1. 竞赛名称匹配成功（竞赛已存在）
2. `missing_competition_name` 未正确传递到模板
3. 模板条件判断错误

**排查方法**：
1. 检查浏览器控制台是否有 JavaScript 错误
2. 检查页面源码，搜索 `missing_competition_name`
3. 检查后端日志，确认是否记录了"竞赛未找到"

### 7.2 快速添加按钮无响应

**可能原因**：
1. JavaScript 函数未定义
2. API 路由错误
3. 认证失败

**排查方法**：
1. 打开浏览器控制台，检查是否有 JavaScript 错误
2. 检查 Network 标签，查看 API 请求是否发送
3. 检查 API 响应状态码和错误信息

### 7.3 添加后下拉框未更新

**可能原因**：
1. JavaScript DOM 操作失败
2. 下拉框 ID 不匹配
3. 竞赛数据格式错误

**排查方法**：
1. 检查浏览器控制台错误
2. 检查 API 返回的 JSON 格式
3. 手动检查 DOM 元素是否存在
