           ├─ winner_name

## 4. 系统处理流程

### 4.1 文件上传处理

```python
# 文件上传处理流程
def handle_file_upload(file, user_id):
    """
    处理文件上传的完整流程
    """
    # 1. 文件验证
    if not allowed_file(file.filename):
        return error("不支持的文件类型")

    # 2. 计算文件哈希
    file_hash = calculate_sha256(file)

    # 3. 检查是否重复
    if exists_by_hash(file_hash):
        return warning("文件已存在")

    # 4. 保存文件
    file_path = save_file(file, file_hash)

    # 5. 调用抽取框架
    result = extract_framework.extract(file_path)

    # 6. 处理抽取结果
    if result.status == ExtractStatus.SUCCESS:
        # 保存到对应表
        if result.template_type == 'award':
            save_award(result.data, file_hash, user_id)
        elif result.template_type == 'patent':
            save_patent(result.data, file_hash, user_id)
        elif result.template_type == 'software':
            save_software(result.data, file_hash, user_id)

        return success(result.data)
    else:
        # 保存到 other_files
        save_other_file(file_path, result.error_message)
        return error(result.error_message)
```

## 8. 关键业务规则

### 8.1 奖状匹配规则

| 规则 | 描述 | 优先级 |
|------|------|--------|
| 竞赛名称完全匹配 | `competition_name_in_file` == `competition.name` | 1 |
| 竞赛别名匹配 | `competition_name_in_file` in `competition.aliases` | 2 |
| 模糊匹配 (Levenshtein) | 相似度 > 0.8 | 3 |
| 关键词匹配 | 包含主要关键词 | 4 |

### 8.2 审核规则

| 状态 | 学生操作 | 教师操作 | 管理员操作 |
|------|---------|---------|-----------|
| `pending_review` | 查看等待 | 审核编辑 | 查看 |
| `invalid` | 编辑重新提交 | 查看历史 | 查看历史 |
| `valid` | 查看归档 | 查看归档 | 查看归档 |

### 8.3 权限规则

| 角色 | 上传 | 编辑自己的 | 编辑他人的 | 审核 | 管理竞赛 |
|------|------|-----------|-----------|------|---------|
| 学生 | ✅ | ✅ | ❌ | ❌ | ❌ |
| 教师 | ❌ | ❌ | ✅ (审核时) | ✅ | ❌ |
| 管理员 | ❌ | ✅ | ✅ | ✅ | ✅ |

## 总结

### 核心业务流程

1. **学生上传** → 系统抽取 → 待审核
2. **教师审核** → 通过/不通过 → 状态更新
3. **归档展示** → 数据统计 → 导出报告

### 需要对接的关键点

1. **文件上传**: 迁移到新的 Extract Framework
2. **数据保存**: 保持现有 Manager 层
3. **审核流程**: 无需变更
4. **数据展示**: 无需变更

### 迁移影响范围

- **影响**: 文件上传和抽取部分
- **不影响**: 审核流程、数据展示、权限管理
- **风险**: 低（隔离良好）
