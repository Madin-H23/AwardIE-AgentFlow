### 测试用例1：文件路径错误测试

**测试目的：** 验证OCR引擎对无效文件路径的处理

**测试步骤：**

### 测试用例3：缓存命中测试

**测试目的：** 验证缓存机制的各种场景

#### 场景3.1：数据库中没有cache，使用高精度访问

**测试步骤：**
1. 清理指定图片的缓存（使用清理函数）
2. 使用`is_precise=True`调用`get_text()`
3. 检查返回结果

**预期结果：**
- `cached=False`（未命中缓存）
- 识别成功，返回文本
- 缓存已保存，`is_precise=True`

**验证方法：**
- 检查返回的`cached`标志
- 检查数据库中的缓存记录
- 验证`is_precise`字段为`true`

#### 场景3.2：数据库中没有cache，使用低精度访问

**测试步骤：**
1. 清理指定图片的缓存
2. 使用`is_precise=False`调用`get_text()`
3. 检查返回结果

**预期结果：**
- `cached=False`（未命中缓存）
- 识别成功，返回文本
- 缓存已保存，`is_precise=False`

**验证方法：**
- 检查返回的`cached`标志
- 检查数据库中的缓存记录
- 验证`is_precise`字段为`false`

#### 场景3.3：数据库中有低精度cache，访问要求高精度

**测试步骤：**
1. 清理指定图片的缓存
2. 使用`is_precise=False`调用`get_text()`（创建低精度缓存）
3. 使用`is_precise=True`调用`get_text()`（要求高精度）
4. 检查返回结果

**预期结果：**
- 第一次调用：`cached=False`，创建低精度缓存
- 第二次调用：`cached=False`（因为需要升级），使用高精度OCR重新识别
- 缓存被更新为高精度结果（`is_precise=True`）

**验证方法：**
- 检查两次调用的`cached`标志
- 检查数据库中的缓存记录（应为高精度）
- 验证缓存被覆盖

#### 场景3.4：数据库中有高精度cache，访问要求高精度

**测试步骤：**
1. 清理指定图片的缓存
2. 使用`is_precise=True`调用`get_text()`（创建高精度缓存）
3. 再次使用`is_precise=True`调用`get_text()`
4. 检查返回结果

**预期结果：**
- 第一次调用：`cached=False`，创建高精度缓存
- 第二次调用：`cached=True`（命中缓存）
- 返回的文本与第一次相同

**验证方法：**
- 检查两次调用的`cached`标志
- 比较两次返回的文本内容（应完全相同）
- 验证第二次调用未执行OCR（通过日志或耗时）

#### 场景3.5：数据库中有高精度cache，访问要求低精度

**测试步骤：**
1. 清理指定图片的缓存
2. 使用`is_precise=True`调用`get_text()`（创建高精度缓存）
3. 使用`is_precise=False`调用`get_text()`（要求低精度）
4. 检查返回结果

**预期结果：**
- 第一次调用：`cached=False`，创建高精度缓存
- 第二次调用：`cached=True`（命中缓存，虽然精度更高但可用）
- 返回的文本与第一次相同

**验证方法：**
- 检查两次调用的`cached`标志
- 比较两次返回的文本内容（应完全相同）

#### 场景3.6：数据库中有低精度cache，访问要求低精度

**测试步骤：**
1. 清理指定图片的缓存
2. 使用`is_precise=False`调用`get_text()`（创建低精度缓存）
3. 再次使用`is_precise=False`调用`get_text()`
4. 检查返回结果

**预期结果：**
- 第一次调用：`cached=False`，创建低精度缓存
- 第二次调用：`cached=True`（命中缓存）
- 返回的文本与第一次相同

**验证方法：**
- 检查两次调用的`cached`标志
- 比较两次返回的文本内容（应完全相同）

#### 场景3.7：禁用缓存测试

**测试步骤：**
1. 清理指定图片的缓存
2. 使用`use_cache=False, is_precise=True`调用`get_text()`
3. 再次使用`use_cache=False, is_precise=True`调用`get_text()`
4. 检查返回结果

**预期结果：**
- 两次调用都返回`cached=False`
- 两次都执行OCR识别

**验证方法：**
- 检查两次调用的`cached`标志（都应为False）
- 检查日志确认两次都执行了OCR

## 测试辅助函数

### 清理图片缓存函数

```python
def clear_image_cache(engine: OCREngine, file_path: str) -> bool:
    """
    清理指定图片的OCR缓存
    
    Args:
        engine: OCREngine实例
        file_path: 图片文件路径
        
    Returns:
        是否清理成功
    """
    try:
        # 计算文件hash
        file_hash = engine._calculate_hash(file_path)
        
        # 删除缓存
        count = engine.cache_db.delete_ocr_cache(file_hash)
        return count > 0
    except Exception as e:
        logger.error(f"清理缓存失败: {e}")
        return False
```
