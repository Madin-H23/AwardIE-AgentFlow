# 数据库结构说明

## 概述

本项目使用SQLite数据库，数据库文件位于 `database/competitions.db`。系统采用关系型数据库设计，通过外键和关联表实现实体之间的关系管理。

## 数据库设计原则

1. **内存缓存优先**: Manager类在内存中维护数据缓存，定期同步到数据库
2. **软删除支持**: 主要数据表使用状态字段而非物理删除
3. **级联操作**: 使用外键约束确保数据一致性
4. **时间戳跟踪**: 大部分表包含created_at和updated_at字段

## 外键关系图

```
competitions (竞赛)
    ├── tracks (赛道) [1:N]
    └── awards (奖状) [1:N]

laboratories (实验室)
    ├── laboratory_instructors (教师) [1:N]
    ├── laboratory_students (学生) [1:N]
    ├── laboratory_assistants (助教) [1:N]
    └── laboratory_images (图片) [1:N]

awards (奖状)
    ├── competition_id → competitions.id
    ├── award_student_winners (学生获奖者) [1:N]
    ├── award_teacher_winners (教师获奖者) [1:N]
    ├── award_supervisors (指导教师) [1:N]
    └── award_related_students (关联学生) [1:N]

students (学生)
    ├── laboratory_students [N:M]
    ├── laboratory_assistants [N:1]
    ├── award_student_winners [N:M]
    └── award_related_students [N:M]

teachers (教师)
    ├── laboratory_instructors [N:1]
    ├── award_teacher_winners [N:M]
    └── award_supervisors [N:M]
```

## 索引

系统为提高查询性能创建了以下索引：

```sql
-- 竞赛相关
CREATE INDEX IF NOT EXISTS idx_tracks_competition ON tracks(competition_id);

-- 奖状相关
CREATE INDEX IF NOT EXISTS idx_awards_competition ON awards(competition_id);
CREATE INDEX IF NOT EXISTS idx_awards_image_hash ON awards(image_hash);

-- 实验室相关
CREATE INDEX IF NOT EXISTS idx_laboratory_instructors_teacher ON laboratory_instructors(teacher_id);
CREATE INDEX IF NOT EXISTS idx_laboratory_students_student ON laboratory_students(student_id);
CREATE INDEX IF NOT EXISTS idx_laboratory_assistants_student ON laboratory_assistants(student_id);

-- 奖状关联表
CREATE INDEX IF NOT EXISTS idx_award_student_winners_student ON award_student_winners(student_id);
CREATE INDEX IF NOT EXISTS idx_award_student_winners_award ON award_student_winners(award_id);
CREATE INDEX IF NOT EXISTS idx_award_teacher_winners_teacher ON award_teacher_winners(teacher_id);
CREATE INDEX IF NOT EXISTS idx_award_teacher_winners_award ON award_teacher_winners(award_id);
CREATE INDEX IF NOT EXISTS idx_award_supervisors_teacher ON award_supervisors(teacher_id);
CREATE INDEX IF NOT EXISTS idx_award_supervisors_award ON award_supervisors(award_id);
CREATE INDEX IF NOT EXISTS idx_award_related_students_student ON award_related_students(student_id);
CREATE INDEX IF NOT EXISTS idx_award_related_students_award ON award_related_students(award_id);
```

## 注意事项

1. **外键约束**: SQLite的外键约束默认未启用，需要在连接时设置 `PRAGMA foreign_keys = ON`
2. **级联删除**: 主要关联表使用 `ON DELETE CASCADE`，删除主记录时自动删除关联记录
3. **数据类型**: TEXT类型存储JSON时需要注意转义和解析
4. **唯一约束**: 学生学号、教师工号等有唯一约束
