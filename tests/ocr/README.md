# OCR 厂商对比测试

统一的 OCR 测试工具，对比不同厂商的识别效果。

## 快速开始

```bash
python tests/ocr/test_ocr.py
```

## 使用说明

运行后会先显示**厂商选择菜单**：

```
============================================================
 选择 OCR 厂商
============================================================

可用的 OCR 厂商:

  1. ZHIPU (API)
  2. PADDLE (本地)
  3. BAIDU (API)

选择方式:
  - 输入数字编号，用空格或逗号分隔多个选项
  - 输入 'all' 或 '*' 选择全部厂商
  - 输入 '0' 取消

============================================================
```

选择厂商后，会显示**测试模式菜单**：

```
============================================================
 OCR 厂商对比测试
============================================================

请选择测试模式:

  1. 使用默认测试路径中的所有图片
     路径: tests/test_images/award/chinese

  2. 指定图片目录路径

  3. 单张图片测试（从默认路径随机选择）

  4. 指定单张图片路径

  0. 退出

============================================================
```

按照提示选择即可完成测试。

## 输出结果

测试完成后会在 `tests/reports/ocr对比报告.html` 生成HTML报告，包含：

- 📊 测试摘要统计
- 🖼️ 原图展示（点击可放大）
- 📝 各厂商识别结果对比
- 📈 相似度矩阵
- ⏱️ 识别耗时统计

## 配置

OCR 厂商配置在 `config/settings.json` 中，支持的厂商：

- **baidu** - 百度 OCR（需要网络和API密钥）
- **zhipu** - 智谱 OCR（需要网络和API密钥）
- **paddle** - PaddleOCR（本地，无需网络）

API 密钥在 `.env` 文件中配置。
