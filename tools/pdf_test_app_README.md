# PDF文本提取测试工具

## 简介

这是一个基于Streamlit的PDF文本提取测试工具，用于测试PDF引擎的文本提取功能。

## 功能特性

1. **自动扫描PDF文件**：自动扫描指定路径下的所有PDF文件（递归搜索）
2. **下拉框选择**：通过下拉框选择要测试的PDF文件
3. **PDF预览**：显示PDF文件的前几页预览（转换为图片）
4. **文本提取**：使用PDF引擎提取文本内容
5. **文本显示**：在右侧显示提取的文本内容
6. **文本下载**：支持下载提取的文本为TXT文件

## 运行方法

### 1. 安装依赖

确保已安装以下依赖：

```bash
pip install streamlit PyMuPDF Pillow
```

### 2. 运行应用

在项目根目录下运行：

```bash
streamlit run tools/pdf_test_app.py
```

或者使用完整路径：

```bash
streamlit run "D:\code\教学工具\信息管理rebuild\tools\pdf_test_app.py"
```

### 3. 访问应用

运行后，浏览器会自动打开应用，或者手动访问：

```
http://localhost:8501
```

## 使用说明

1. **选择PDF文件**：
   - 应用会自动扫描基础路径下的所有PDF文件
   - 使用下拉框选择要测试的PDF文件

2. **查看PDF预览**：
   - 左侧会显示PDF的前几页预览
   - 可以通过滑块调整显示的页数（1-10页）

3. **提取文本**：
   - 点击右侧的"提取文本"按钮
   - 等待提取完成

4. **查看文本**：
   - 提取完成后，右侧会显示文本内容
   - 可以查看文本统计信息（字符数、行数）
   - 支持下载文本为TXT文件

## 配置

### 基础路径

默认基础路径为：
```
D:\code\教学工具\信息管理rebuild\images\奖状
```

可以在侧边栏的"基础路径"输入框中修改路径。

## 界面布局

- **左侧**：PDF预览区域
  - 显示PDF页面的图片预览
  - 可调整显示的页数

- **右侧**：文本提取区域
  - 提取文本按钮
  - 文本统计信息
  - 文本内容显示
  - 下载按钮

## 注意事项

1. 确保PyMuPDF已正确安装
2. 确保基础路径存在且可访问
3. PDF文件较大时，提取可能需要一些时间
4. PDF预览功能需要PyMuPDF支持

## 故障排除

### 问题：找不到PDF文件

**解决方案**：
- 检查基础路径是否正确
- 确保路径下存在PDF文件
- 检查文件权限

### 问题：PyMuPDF未安装

**解决方案**：
```bash
pip install PyMuPDF
```

### 问题：无法显示PDF预览

**解决方案**：
- 确保PyMuPDF已安装
- 检查PDF文件是否损坏
- 尝试重新加载页面

## 技术栈

- **Streamlit**：Web应用框架
- **PyMuPDF (fitz)**：PDF处理库
- **Pillow (PIL)**：图片处理库
