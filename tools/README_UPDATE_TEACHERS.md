# 教师通讯录更新工具

## 功能说明

从 Excel 通讯录文件更新数据库中的教师信息（工号、手机号、职称），并新增通讯录中存在但数据库中不存在的教师。

## 使用方法

### 1. 预览模式（推荐先执行）

```bash
python tools/update_teachers_from_contacts.py --dry-run
```

预览模式会显示将要更新和新增的记录，但不会实际修改数据库。

### 2. 正式执行

```bash
python tools/update_teachers_from_contacts.py
```

### 3. 指定自定义文件路径

```bash
python tools/update_teachers_from_contacts.py /path/to/contacts.xls
```

## Excel 文件格式要求

- 文件格式：`.xls` 或 `.xlsx`
- 布局：双列布局（每行2位教师）
- 必需列：姓名、工号、手机号
- 可选列：职称
- 前3行为标题行，从第4行开始是数据

## 注意事项

1. **备份**：执行前请确保已提交 git 或备份数据库
2. **匹配规则**：按姓名精确匹配（不区分大小写）
3. **默认部门**：新增教师的部门默认为"计算机工程系"
4. **工号唯一性**：确保通讯录中的工号不重复

## 技术实现

### 核心函数

- `parse_contacts_excel()`: 解析 Excel 文件，提取教师数据
- `match_teachers()`: 按姓名匹配现有教师
- `update_teacher_info()`: 更新教师信息
- `insert_new_teacher()`: 插入新教师
- `main()`: 主流程，协调整个更新过程
